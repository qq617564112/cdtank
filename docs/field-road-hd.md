# 田野路（高清）

地图 ID 为 `1002`，原版田野路为 `2`。高清地图继承原版的五种模式配置、出生点、导航、碰撞、城堡和场景物件位置。房间地图选择器与雷达使用独立的高清俯视图。

85 张贴图保留源 UV 坐标、透明遮罩、道路连接与地形边界。19 个 GLB 模型使用高清 PNG，几何、UV、顶点颜色、动画、材质和采样配置沿用原资源。城堡各状态及物件破坏后的贴图使用同一套高清交付。

| 类别 | 每张贴图尺寸 |
| --- | --- |
| 路面 | 1024×1024；`lu01`、`lu15` 为 2048×2048 |
| 植物、地形、屋顶、木桶、围栏等 | 1024×1024 |
| 天空、房屋和城堡图集 | 1920×1920；`obj05448A` 为 2048×2048 |
| 32 帧水纹 | 256×256 |

贴图位于 `art/hd/custom-maps/1002/Data/`，地图预览位于 `art/hd/custom-maps/1002/preview.png`。`art/hd/field-road.json` 记录模型与贴图对应关系。

## 安装

原游戏资源安装完毕后，运行：

```sh
npm run assets:field-road-hd
```

该命令复制场景、战场、移动数据及相关资源，生成独立的高清 GLB，并登记音乐与地图选择器预览。`assets:custom-maps` 包含高清地图导出。运行图片保持单独文件引用。
