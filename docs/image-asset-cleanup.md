# 图片资源清理

发布图片为 158 份，共 2,199,999,730 字节。清理前为 463 份、3,014,304,337 字节，减少 305 份图片和 814,304,607 字节，图片数量减少 65.87%，图片体积减少 27.01%。

清理了 3,056 个无引用图片路径，包括旧界面整张图集、生成中间图、布局预览、原加载背景、未使用贴图和被优先版本覆盖的界面区域。32 份被同名 DDS 版本覆盖的 imageset 目录项已移除；按具体目录路径使用的战斗文字附图仍保留。

4,859 个图片路径共用 4,186 个精灵格子，673 份重复像素共用格子；一份独立登录背景副本的目录引用已改为共享背景。此次新增合并 85 份重复图片。图集共 141 张，另保留 15 张独立大图、一张 SVG 地图预览和一个 ICO 图标。

引用扫描从游戏和参考角色两个入口沿运行模块的静态导入及动态导入追踪，覆盖 596 个模块。固定循环中的图片名称逐项解析，动态资源目录匹配实际文件。163 份关联 JSON 目录及其引用的子目录、内容定义和全部 986 个发布模型共同确定使用范围。预加载清单不作为业务引用。

UI、坦克皮肤、宠物、聊天表情和地图的目录资源保留。聊天图片标签可以按名称访问所选 imageset 中的任意图片，因此保留这些资源及其中 144 个普通字图。普通 UI 控件采用字体绘制，聊天图片标签通过共享精灵格子读取原图。

4,186 个独立精灵格子与原图逐 RGBA 通道比较一致。所有 4,442 条模型外部图片引用均有有效资源。当前已发布图片没有无引用项，裁切范围及备份完整。

原图和工作素材保存在发布目录之外：

- `art/hd-assets/unused-images`：121 份移除的独立图片及原目录元数据。
- `art/hd-assets/sprite-originals`：精灵图的独立原文件，也保留 2,936 份已移出精灵目录的原图。
- `art/hd-assets/uncompressed` 和 `art/hd-assets/original`：高清未压缩版本及原始美术。

清理和重新打包：

```sh
npm run assets:clean-images
python3 scripts/preview-image-sprites.py
```

只生成清理计划：

```sh
python3 scripts/clean-image-assets.py --plan-only
```

恢复被移除的独立图片：

```sh
python3 scripts/clean-image-assets.py --restore
```

当前精灵目录继续可用，恢复不会改动现有图片引用。高清资源重装结束会自动清理并重新打包。

统计在 `art/hd-assets/image-cleanup.json`，原文件位置在 `unused-images/manifest.json`，当前引用和备份核对在 `image-cleanup-inspection.json`。预览为 `art/hd-assets/sprite-preview.html`。
