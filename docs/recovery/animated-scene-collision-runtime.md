# 动画场景碰撞静态化

CVD、GLB、Castle 和 Plant 的碰撞在资产构建阶段固定到首帧，并随地形、静态物件和 NAV 占用写入 `apps/web/public/scene-collision/<地图编号>.json`。运行时直接构造碰撞网格，不再读取 GLB/CVD、采样节点变换、插值顶点帧或在每个服务端 tick 重建动态占用。

构建导出复用原有转换后的模型格式：CVD 读取时间零节点层级和顶点帧，GLB 读取时间零节点／morph 状态，Castle 使用 `n1` 首帧，Plant 使用确定初相下的首帧接触 OBB。导出的碰撞网格包含三角面、法线、AABB 和 128 单位空间格；NAV 占用按 12 单位格单独预计算。

客户端继续按原动画资产绘制模型；服务端碰撞不再与渲染播放同步变化。破坏、Crush 显隐和 Castle 替换仍通过动态目标业务状态切换静态碰撞占用，`animatedBlockers` 快照保持为空数组以避免协议变更。

本轮仅修改构建与加载路径，没有运行测试、构建、类型检查或浏览器验收。
