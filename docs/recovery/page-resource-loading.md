# 页面静态资源加载

设置、我的家、商城、交易、等待房间、战斗HUD、聊天、结算及使用 `useSourceUi` 的页面共用静态目录缓存。`assets/static-resources.ts` 按URL共享请求Promise和解析结果；相同目录在一次应用运行期间只请求和解析一次，失败后删除该项，下次载入重新请求。页面卸载只停止更新自身状态，共享请求由加载器管理。

页面首帧通过 `cachedSourceUi`、`preparedCombatCatalog`、`preparedTankCatalog` 和 `preparedTankTextureCatalog` 读取本次启动已准备的目录。等待房间、设置、我的家、商城、交易、HUD、CPU配给及迷彩页不再先清空静态界面后通过effect回填；我的家刷新账户资料时保留静态布局。结算页复用完整图片及字体准备成功后的目录，仍等待本次声音实例就绪。账户、库存、拥有角色、商品价格和钱包继续查询服务端当前状态。

纳入缓存的目录包括 `ui.json`、`ui-fonts.json`、`combat-catalog.json`、`tanks.json`、`tank-textures.json` 和 `chat-emote-sequences.json`。战斗角色和场景文字也复用UI及字体目录。账户、库存、商城等业务查询继续读取服务端当前状态。

战斗加载阶段还共享GLB和音频的完整文件，以及音频解码结果；动态模型的外部贴图复用图片缓存。战斗开始前准备当前地图、全部参战角色和本局可能出现的陷阱、掉落物、伪装、音效与音乐，完成后才确认本局就绪。完整范围及通信字段见 `room-loading-flow.md`。

JSON请求及响应体读取使用30秒超时，超时中止请求。原界面图片解码和动态字体加载也设置30秒超时；失败清除对应Promise缓存。设置页和大厅提供原地重试，其余页面通过重新打开或既有资源重试入口再次载入。

页面复用 `loadUiFont` 加载当前选用的香蕉字体，启动图片加载页也复用同一Promise。字体采用 `font-display: swap` 和30秒超时；页面内容不再等待字体加载。原完整SIMSUN动态字体不参与当前页面加载，战斗伤害等静态字形仍读取 `ui-fonts.json` 并等待其必要图像资源。字体加载完成后重新计算聊天换行和输入光标位置。

JSON、图片和字体已经作为Vite的public静态资源随前端发布，运行时按需读取。大型目录保留独立文件，避免扩大入口JavaScript；页面切换复用内存中的解析结果。JSON、GLB和音频的完整文件写入 `cdtank-static-resources` IndexedDB，按发布目录记录的修改时间复用；浏览器刷新后可读取匹配版本的本地文件。未注册版本的地址沿用网络读取。

首次Loading下载并解码UI图集、独立UI图片及源码图标、缩略图，再进入游戏。按最终发布地址去重，坦克皮肤、地图、模型和场景贴图由实际使用流程加载。页面图片准备与Loading共用 `assets/image-resources.ts` 的解码缓存，后续页面直接复用；失败重试保留成功图片。图片缓存命中只代表下载已完成，本次应用启动仍等待UI解码。详见 `image-loading-runtime.md`。

启动布局准备包含等待房间、房间聊天频道菜单和战斗聊天布局，引用的精灵图区域在准备完成前裁切并缓存。正式聊天仅在WAITING显示等待聊天页，在PLAYING/FINISHED按编辑或消息通知状态显示；资源未就绪、阶段未确定或LOADING期间保持隐藏，加载失败经共用消息弹窗反馈。

## 手动加载资源包

登录页“加载资源包”确认后才调用 `assets/preload-resources.ts`，进入共用Loading界面。`image-assets.json` 的 `resources` 目录列出发布的public文件、`/content`定义和生产构建产物；生产目录在Vite完成CSS和HTML入口处理后生成。该目录的注册只设置版本，不触发地图、模型或音频下载。默认启动的界面图片预加载范围保持不变。

全量加载按最终资源地址去重，使用最多8个并发下载。图片复用 `cdtank-image-assets`，其它文件写入 `cdtank-static-resources`；每个文件完整写入后才累计进度。未使用的图片留在磁盘，不提前解码，GLB和音频也不提前创建场景实例或解码音频。实际使用时，模型加载器、Babylon贴图入口、场景JSON与音频加载器读取相同缓存。资源全部完成后返回登录页并显示完成提示；失败弹窗可重试或返回，已写入的文件保留。资源下载设置30秒超时。
