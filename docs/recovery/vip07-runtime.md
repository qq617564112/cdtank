# 擒王地图0007托管避让

普通托管王在受伤、近距离目标可见且炮塔尚未对准时，尝试普通前进或后退并转动车身，选择碰撞预测允许、能增加与最近活敌人距离的输入。没有可用方向就维持既有路径行为。仅改变CPU输入意图，不修改角色位置、生命、弹丸、王身份或终局规则。

`battle/cpu/vip-evasion.ts` 负责避让候选选择，controller仅判当前资格并提交输入。候选使用已有原移动预测；没有完整来源时沿现有明确重建移动计算。提交的输入仍由 World 普通资格、原门禁及碰撞执行。转动车身时炮塔瞄准按预计实际位置/朝向重新计算。健康王、非王、其他模式及被阻挡方向不触发这项避让。

## 依据和验收

原完整服务器王策略未知，本项明确为重建AI。`vip07-diagnostic.json`保存修改前普通输入轨迹：P1敌王距离179.72，目标可见无友方阻挡；近距离停驻产生43个move0/turn0输入，炮塔初始误差2.893弧度、至少3.15秒瞄准，在2.15秒自然王死亡结束。关闭新增环境物件的同断言失败证据沿上一轮保留；诊断没有改位置/伤害或终局。

`vip07-evasion-rules.log`覆盖受伤王前进避让与车身转向、原预测受阻不绕过、健康/非王/其他模式不改变。`vip07-autopilot-turn-fixed{-mode3}.json/log`由原失败连续两局普通输入夹具通过，实际移动、开火、命中、自然OBJECTIVE、冻结结果、再战重置和离房通过。`vip07-autopilot-team-regression`模式1/map7两局通过，环境原资格和油桶接线没有破坏正常团队对局。

真实网络和正式网页专项另由 vip07-network/browser 文档记录；模拟World只能支持规则与连续两局，不替代网页真实操作。原服务器HP倍率、王选择/出生/复活和完整玩法精度仍保留M2-08父项。
