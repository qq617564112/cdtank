# 战斗目录与属性重算边界

E-02将combat-catalog读取及物品/技能/被动技能/数据限制索引移入battle/catalog.ts。World和属性模块使用同一份正式目录与索引，资产路径继续通过runtime/content-paths配置，不重新解析目录或复制状态。

battle/attributes.ts负责完整拥有来源的属性重算，接收实际角色状态而不依赖World类。它保持基础/装备字段、战车/宠物定义及角色字段完整性门槛；缺失字段不填零，VIP来源未恢复时不推定倍数，独立boundGear不补造。技能实例解析、部件技能索引、原初始移动尺度及完整433466调用保持原样。

World继续负责账户确认与准备阶段权限、装备实例到表ID转换、准备取消、开局冻结和调用时机；模块写回同一角色的属性状态和就绪标记。World现916行。伤害、完整移动尺度来源、VIP和特殊弹药仍按M2原规则恢复，不因结构迁移宣称完成。

迁移后验收通过：564完整433466原调用、126原初始来源重算及正式World全部属性对照、21战车普通默认弹药装填和开局生命；210战车宠物归属绑定、32装备来源向量、204物品分类与74被动技能选择；五模式结算冻结/再战、编译真实账户与迷彩联机重启保存、CPU五模式各两局、构建/类型及180模块运行依赖边界。日志为engineering-attributes-{build,native,sources,match,compiled,types,boundaries}.log。
