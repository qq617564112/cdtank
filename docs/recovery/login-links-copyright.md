# 登录页外链与版权声明

登录页保留木牌图与800×600基准布局。右侧木牌文字为“游戏介绍”，打开 [百度百科原作条目](https://baike.baidu.com/item/%E9%98%BF%E7%8C%AB%E9%98%BF%E7%8B%97%E5%A4%A7%E4%BD%9C%E6%88%98/1715847)；左侧第一块木牌文字为“项目主页”，打开 [项目仓库](https://github.com/qq617564112/cdtank)。两者使用真实链接和 `target="_blank"`、`rel="noopener noreferrer"`，支持鼠标与键盘访问。“项目主页”木牌基准宽161、高47，第二块“加载资源包”木牌基准宽166、高48。系统设置位于下一行，基准top460，对应原 `login.xml` 的 `btnSettings`。

“加载资源包”先显示原生确认dialog，说明将一次性加载并缓存所有游戏静态资源，并按当前资源目录的文件字节数显示资源包约多少GB，保留一位小数。取消留在登录页，确认进入共用Loading界面；资源全部写入本地缓存后返回登录页，保留已输入的账号和密码。加载失败提供重试与返回入口，重试复用已完成的缓存。默认启动仍只预加载界面图片，地图、模型和音频保持按需加载。资源包范围和缓存见 [页面静态资源加载](page-resource-loading.md)。

页面底部显示原作版权归属、CDTank贡献者版权和“源码公开，仅供非商业研究，禁止商用”声明。源码许可入口在新标签页打开仓库 `LICENSE`。版权页脚独立于登录表单和资源准备状态。
