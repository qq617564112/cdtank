# 自主有限弹药

M2-02-AMMO-AI-B在正式BotController的普通输入出口选择已交付的有限弹药。玩家为托管账户配置2007或2011后，AI在存活、角色状态2、当前确认普通2001且实际可开火机会时，寻找槽2–4的首个对应库存实例；拥有量与本局量均须大于0。只生成普通useItem槽号，确认、资格、数量和CAS持久消费仍由既有权威模块处理。

该选择策略是重建AI规则，不证明原客户端或服务器AI。治疗、饮料和团队存量现有优先级保持；初始普通弹选择不改变。已确认特殊弹时不重复选槽，末颗保持原弹种，随后零量开火由既有消费模块拒绝并恢复默认，下一普通输入继续开火。没有注入角色位置、生命、伤害或胜负；不改变弹速、装填、伤害和渲染资源。

生产归属battle/cpu/items.ts的finiteAmmoHotkey与controller.ts的finishItems出口，shared与World无需重复规则。tests/ammo-ai-policy.cts验证存活/状态/当前弹种/可开火资格、实际高位unsigned实例映射、耗尽槽后继选择及未交付有限弹种排除。实际托管网络、网页和持久恢复由专属验收记录，不以该政策测试代替玩家闭环。
