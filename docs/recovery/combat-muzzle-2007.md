# 燃烧弹原炮口表现

M4-09-COMBAT-MUZZLE-2007：PASS。正式 React 大厅的两个网页通过普通建房、加入、Ready、Digit2 与 Space，消费服务端确认的燃烧弹 2007。两端实际绘制原 054 五个节点，播放并自然结束 GA09；Digit1 恢复普通炮弹 004/GA07。真实死亡后复活重置为 2001，正常再战与离房释放通过。

## 限制

本切片确认原炮口绘声和明确重建的选择业务，不实现尚未确认的原耗弹、持续燃烧伤害、飞行轨迹、落点或命中触发。现有世界 Shot 使用物品第二表现槽，2007该槽为0/声音0；这不表示 skill4005全部效果静默。截图没有效果开关像素差归因。软件渲染的320×180画布不证明高分辨率性能；短寿命原节点未冻结，亦不保证每个开火实例在慢帧下都完整提交。复活后确认重置由实际快照及正式消费者测试验证，未额外要求复活后再次开火。
