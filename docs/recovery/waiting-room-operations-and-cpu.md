# 等待房间操作与CPU管理

M5-03/UI-44：正式等待房间沿800×600基准缩放，原十二个源名单槽继续显示权威成员、队伍与准备状态，超出源槽的成员显示在overflow区域。源Ready、CancelReady、ChangeTeam、Invite与Leave继续调用既有房间接口。

等待页侧栏显示已确认的房名、房号、模式、地图、时限、人数、准备人数、密码与友伤状态。CPU区域显示当前CPU数量、名称和已配置的有效配给槽数，并容纳既有CPU添加、移除、配给与托管操作。此侧栏是Web界面装配，原room_main控件和图片继续沿源区域呈现。

操作状态区区分资源载入、请求等待、失败、邀请确认和正常状态。Ready、取消准备、换队、邀请与离房请求持有自己的操作名称，完成后按既有页面代际清理；异步失败沿原通知对话框显示。请求期间继续禁用重复提交，界面读取权威快照。

所有动态文字由全局附件字体消费。CPU管理、状态与overflow区域随同一viewport scale缩放，键鼠隔离和原通知/退出路径继续复用现消费者。
