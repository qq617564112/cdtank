# M5-02-F 建房友伤

普通建房页提供“允许伤害队友”开关，团队模式可设置，个人模式禁用并清零。当前选择发送CreateRoom，由服务器决定资格并存房间独立状态；目录和两端等待面板显示服务器确认。房间临时状态不承诺重启恢复。

## 原来源与重建边界

原createroom.xml有rdoFriendlyFireOff与rdoFriendlyFireOn。现有客户端布局足以确认功能存在，完整原按钮处理、各模式资格、服务器计分和友方击毁胜负规则未恢复。默认关闭保持现有重建服务行为，不宣称原XML选中属性或完整原服务器默认。原地图BrokenScore保持现有误伤惩罚；开启实际扣血、防护及死亡、正奖励禁止、同队生命/VIP损失判对方胜均明确为重建规则，完整原规则仍由M2/M5/UI-07恢复。

## 业务合同

仅模式1至3接受true，其余true拒绝，省略按false；非法类型或模式在分配房间前拒绝。创建重试按归一开关比较，不改已有房间配置。关闭命中队友保持原生命且记录原有friendlyFire/惩罚；开启命中队友真实受伤，防御/无敌适用，禁止给攻击者正命中/击毁奖励或友方击杀数。普通死亡复活、对局冻结再战保持既有life。CPU保持敌方目标与避免友军射线，不做友伤AI功能扩展。

正式归rooms状态与创建校验、battle/life及玩法击毁判定；World只编排。客户端lobby操作、Battle传请求、等待面板投影；shared仅新增可选协议。原取证不进入运行路径，效果资源不改。

验收须含普通输入真实弹丸ON/OFF、双端事件与生命状态；规则夹具只能验证计分/防护边界，不能代替可玩对局。正常页面/1080p4K、联机设置及拒绝、相关五模式CPU两局/账户保存、独立构建与类型保护基线。
