# 非UI射击射程与命中

全部23种炮弹在开火查询时直接处理选中的玩家或场景目标，没有距离相关的飞行等待。弹药定义统一使用`runtime.query: instant`，不创建独立bullet。

## 最终行为

| 环节 | 合同 |
| --- | --- |
| 目标查询 | 默认射程1000；FuncType23按采用的总范围百分比换算。所有炮弹使用现有XZ半宽25的玩家筛选和场景遮挡查询；FuncType22保留穿透目标选择。 |
| 开火时序 | 接受开火后启动03动作，约0.4秒回调查询目标，在同一次处理内发送fire和对应命中结果。 |
| 玩家命中 | 使用接受开火时冻结的弹药ID和技能修正，保留该弹药的伤害、治疗、燃烧、减速等命中处理。 |
| 场景命中 | 保留可破坏物、目标建筑和不可破坏表面的既有资格及结果分派。 |
| 命中表现 | 无伤害显示烟团，有伤害显示命中闪光；可破坏物的原粒子仍从接触点下方地面发出。 |

弹药属性决定的装填间隔、有限库存消费和射程继续由现有消费者处理。`projectileSpeed`不参与即时判定的命中耗时。

## Web显示

炮口、场景端点和受害者命中特效保持各自入口。全部炮弹不写入`MsgRoomSnapshot.bullets`，BattleProjectiles没有可显示的飞行本体或尾迹。

## 来源边界

约0.4秒回调查询来自原定时与接收链；普通1000查询、场景等距离选择及显示端点算术来自原4288fe/4289e7相关执行。显示链`423956`至`489ba8`只把入口XYZ和所选技能效果参数交给显示/声音接口，没有提供原独立弹丸的创建、速度、寿命或轨迹来源。

全部弹药统一即时判定为当前Web采用规则，未认定它等同原版特殊弹的时序。水平30炮口和Y+20用于当前接触点计算，仍是Web采用值；原弹速、独立飞行实体、原FuncType22/23服务端分派及最终攻防公式未恢复。

本页只记录静态核对后的最终行为和来源边界。未运行测试、浏览器、构建、类型检查、lint、导出器或原生取证。
