# 战斗道具取得

光学迷彩9、南瓜变身10、木桶变身11、1UP501、建筑工具502、精品饲料罐头3006和定时闹钟3007通过破坏物掉落及结算奖励进入普通玩家库存。原零价格、getMethod、Shop与交易字段保留；取得走已有账户事务、回执和库存通知。

## 取得规则

七件定义的`runtime.values.breachDropOrder`按上述顺序为6–12，`battleRewardOrder`为19–25。这是项目采用的取得池规则，不是原服务端概率的恢复。

五模式普通Breach击毁使用现有50%掉落概率，每次成功从12项池等概率选择一件、数量1；原五项饲料、雷达干扰弹与鱼骨/骨头仍在池中。Castle、Plant、Crush不参与。模型、纹理、拾取音效沿原dropitem类别/数量档位选择；地面实体30秒回收、拾取CAS、回执去重、同账户库存广播与本局自动空槽沿既有链。添加七件后，原五件各自的成功掉落概率为1/12。

结算沿既有完赛、真实PLAYING至少60秒、combatScore大于0和非FORFEIT资格，25%抽一件道具；在现有池中加入七件，不另加独立抽签。原冻结抽签、BEGIN IMMEDIATE、库存新实例、账户奖励回执、结算图标弹窗与留房库存同步保持。重试不会再抽签或重复发奖。

## 使用

取得不自动使用。新拾取实例仅填本局对应栏的空槽；满栏仍取得库存，结算奖励不自动装槽。普通Home配置和战斗快捷输入消费真实数量。1UP和建筑工具的使用资格仍沿玩法/城堡规则；取得不绕过这些条件。CPU沿既有有限本局库存规则，不写入真人账户。

## 验收边界

源码和发布定义已接。原取得条件与概率仍缺来源，采用规则已明确；新增池的普通对局、持久到账、双端和页面表现尚未实测。已有五项池的验收不扩展为12项已实测，M2-10/M4-10/M6父项保持开放。
