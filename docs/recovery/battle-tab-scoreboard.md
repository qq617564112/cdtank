# Tab 与战斗计分板

页面入口以捕获阶段监听 `keydown`/`keyup`，统一取消 Tab 的默认行为，包括输入框和 Shift+Tab。监听不阻止事件传播；Tab 保留给游戏功能，不切换页面焦点。

正式战斗画面按住 Tab 显示计分板，松开关闭。窗口失焦、页面隐藏、离开对局、终局和局号变化均清理显示状态。计分板不暂停战斗、不取得焦点；CPU 托管及死亡等待期间也可查看。

计分板复用 `game_summary.xml` 的猫狗面板、分数标题、战车击毁/物件数标题、蓝色条目、绿色本人条目与原宠物头像。动态文字沿用全局字体。以原 800×600 布局适配窗口尺寸，不显示胜负、结局加分或结算奖励。

数据来自服务器 `PlayerSnapshot`，显示实时得分、击毁数、死亡数；破坏模式的第二数值列显示摧毁物件数。团队模式分猫狗两列，个人模式显示个人排名；名单超过原单列六格时可分页。`BattleScoreboard` 仅发布参赛者与分数字段变化，移动和计时快照不触发计分板重绘。不新增协议、请求或账户写入。
