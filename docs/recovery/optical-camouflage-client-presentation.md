# M4-10-I09 光学迷彩客户端显示

服务端按已确认的普通自用施放投影 `PlayerSnapshot.opticalCamouflage = {skillId: 9, expiresAt}`。BattlePlayers 读取该权威字段与共享观察规则，不自行计时，也不在本地推定施放成功。

## 观察规则

`isHiddenByOpticalCamouflage` 对存活、skill9 生效、且非观察者自身的角色，在观察者为敌对时返回真。本机始终可见；团队模式1–3中同队可见，仅敌对队伍隐藏；混战/破坏模式4–5中其他所有参与者均视为敌对。网页仅在 `PLAYING` 且判定隐藏时对该角色 root 调用 `setEnabled(false)`。非 `PLAYING` 阶段恢复普通显示；伪装替身的 actor 隐藏另按伪装合同处理。

敌对观察者看不到隐藏角色的车体、饰品、头顶名称/血条、雷达标记、伤害/收益/暴击/连杀飘字和角色归属特效。激活隐藏或切换观察者时清除已存在的飘字，隐藏期间不排入新飘字；附着特效继续推进时钟与释放资源，只停止绘制。场景特效、已发射弹丸与全局 HUD 名册沿用既有路径。相机、位置、插值、动作状态、模型生命周期和命中规则不变；临时隐身不释放或重载战车。

Web 采用自身与队友可见的35%不透明度作为光学迷彩表现：MV3 shader 在原纹理 alpha 拒绝之后乘角色不透明度，并启用 alpha 混合；饰品同步半透明，黑色描边暂停。所有已载入动作和后续动作载入使用该角色当前不透明度，效果结束恢复原材质混合与描边。该透明度是 Web 表现选择；skill9 的 Effect/Sound 槽均为0，原版透明度、折射与材质切换规则尚未恢复。

CPU 与自动驾驶使用 `isHiddenFromOpponent` 排除光学迷彩或伪装中的敌人。当前目标离开候选集时清除导航、反应与待确认扳机，停止按其位置追踪；隐藏不阻止普通弹丸碰撞和伤害。

## 生命周期与载入

可见性由服务端快照驱动。快照中该项移除、到期、角色死亡、结算或换局时恢复显示；`playing=false` 时一律显示角色。继续渲染/对账会按最新快照、观察者与模式重算可见性，切换观察者、队伍或模式同样重算。`clear()` 归还全部普通状态与观察者/模式默认值。

迟到的战车载入在插入场景并将资源挂到特效系统之前，使用当时的快照、观察者与模式设置可见性，避免隐藏敌人短暂出现。

## 范围

不新增 Effect、Sound 或标记索引，不把隐身当作碰撞免疫或无敌，也不因普通开火取消。CPU 配置界面槽5–8按已确认目录开放物件9（上限仍取该物件 BattleUseMax）；购买、键盘焦点、保存与生成沿既有流程。
