# 本机坦克运动

手动控制的坦克由客户端计算位置、车体朝向和炮塔方向，每个渲染帧推进并呈现。服务端接受同一局、同一生命的姿态上报，沿移动与车体转向路径处理其它存活坦克接触，记录后广播给房间；普通快照确认不覆盖本机姿态。最新快照中从服务端确认位置到本机位置的路径无法通过接触处理时，本机恢复该确认姿态。

`PlayerInput.pose`携带round、life（死亡次数）、原坐标x/y/z、yaw/bodyYaw/aim和运动command。既有输入sequence保持消息顺序。姿态在道具请求处理之前安装，开火、地雷和命中查询使用已接收的位置。出生、复活、新局及从自动驾驶恢复手动控制时初始化本机姿态。

`PlayerSnapshot.movement`提供统一数值链算出的速度、转速、TankType和当前运动许可。确定性运动数学、NAV采样、OBB判定和渲染面碰撞占用由`apps/shared/movement`供两端共用。客户端读取原NAV及已加载场景的完好渲染面，随破坏和Crush状态更新占用；Plant沿既有穿行接触消费者处理。

电脑键盘采用车身与炮塔联动：车身转向带动炮塔，炮塔输入调整相对角度aim，炮塔世界朝向为yaw+aim。

手机摇杆使用内部连续方向向量，以独立相机朝向为基准。前半球对齐车头并前进，后半球对齐车尾并倒车；正左右及水平轴两侧各3°范围持续原地转向。目标方向误差超过60°时先原地转，误差减小后沿车头前进或沿车尾倒退。行驶速度随摇杆行程变化。方向向量仅用于客户端运动计算，上报仍采用原有姿态及command字段，倒车使用2、7、8命令。

手机车身转向时补偿相对炮塔角度，使世界瞄准方向及相机朝向保持独立；右侧拖动按当前炮塔转速的30%、60%、100%更新世界方向。摇杆目标每帧随当前相机朝向更新。固定炮塔车型继续沿bodyYaw瞄准。操作及浏览器记录见[手机战斗界面](../mobile-battle-ui.md)。

服务端不推进已上报姿态的手动玩家；CPU、自动驾驶和只上传按键的独立输入消费者继续使用服务端运动入口。伤害、弹药、技能、死亡和结算仍由服务端处理。其他坦克沿快照插值显示，相机跟随本机连续姿态。

所有存活坦克统一使用现有49×24×52车体OBB参与阻挡，不以完整属性来源或运动参数存在与否过滤。客户端与服务端共用`tank-collision.ts`，检查实际移动和车体旋转，死亡角色不占用车体位置。复活先选择未占用的原出生点，再选择其附近完整NAV落脚范围可用的位置；无空位时维持死亡状态并在后续节拍重试。同一节拍逐个确认复活位置，成功后才发布respawn事件。该生产占用与放置规则未执行真实双网页、连续复活或拥挤出生点验收。

车体转向接触另一坦克或场景阻挡时，按水平分离轴给当前车体让位。已有接触预算取联合分离实际需要的累计距离，墙角两面分别计入；旋转新增预算按两个水平方向的车角扫掠距离限制，并保留0.05单位接触间隙。让位后的完整49×52足迹及中心路径必须通过当前NAV和模型占用；足迹检查遍历水平包围范围内的格子，用旋转矩形与格子矩形的分离轴判定确认实际覆盖区域，其它坦克和场景物体的位置不变。无法继续行驶时，先停在可接受姿态，再尝试剩余车体转向；空间不足时保留最后可接受角度。CPU和自动驾驶通过实际步进处理存活车体接触，静态接触通知独立保留。

场景接触读取当前NAV中由渲染模型登记的占用格，包含地形立面、静态模型、完好的可破坏物体和仍在破坏淡出期的物体。仅收集本次车体扫掠和让位范围内的格子，相邻格先合并为矩形，再与其它坦克一起参与接触分离，避免格缝打断贴靠转向。占用按每次移动实时读取：可破坏物体严格超过2000ms后随既有淡出规则释放，恢复时重新参与；Crush隐藏或停用时沿现有规则释放。该接触矩形只用于水平移动，射击继续使用已烘焙模型三角面。

模型导航沿移动路径以不超过6单位的间隔采样。左前、右前、左后、右后均进入同一套接触让位处理。前进或倒车转向的路径受阻时，原运动弧线按实际旋转方向退回原地车体转向：命令5/8退回4，命令6/7退回3，倒车受阻前后保持旋转方向一致。手机连续摇杆保留本帧目标车体朝向并取消位移。两端共用导航路径检查，原地转向先检查原NAV中心通行，再进入车体与场景接触处理。该接触转向调整仅完成源码走查，实际贴靠、墙角及多人拥挤手感仍待运行验收。

垂直运动与本机姿态上报同源：本机在推进或静止时用共享`tank-vertical.ts`按原NAV有效格子中心之间的连续高度推进物理Y，服务端手动分支只接受上报姿态、不二次推进垂直；CPU、自动驾驶与服务端权威运动共用同一高度与垂直步。已落地车体跟随小下降，离地车体继续使用重力。水平核与`forward.y === 0`严格采样不变，出生与复活使用同一连续高度，垂直状态在开局、复活、再战和托管切换时重置。协议沿用现有x/y/z，不新增字段。重力常量与落脚限高为明确项目采用规则，见`battle-vertical-physics.md`。

离房或取消载入清除本机运动和地图导航所有权；同一生命的断线恢复保留本机姿态。客户端和服务端使用同一份更新后的TSRPC协议。
