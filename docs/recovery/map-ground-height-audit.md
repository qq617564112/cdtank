# 地图贴地高度排查

2026-10-14，26 张地图的发布 NAV 均与服务端源数据一致，初始地形及物件占用也一致。11 张地图存在大于贴地容差 0.5 的可通行邻格高度差，共享连续高度采样覆盖全部地图、手动运动、CPU、托管、出生、复活和车身坡面。

## 处理规则

`NavigationGrid.groundHeightAt` 在原有效格子中心之间做双线性插值，并按有效高度的权重归一化，返回 f32。原离散单元、足迹通行、路径扫掠、占用和导出 NAV 字节继续按既有规则参与判定；动态物件增减占用不改变地形高度。车体坡面的五个点使用同一高度场，侧面物件占用不会把整车倾角突然清零；缺少原高度贡献的单侧使用中心高度。

已落地且垂直速度非正的坦克跟随不超过 18 的小下降。更大下降或已经离地时继续重力积分。实际显示 Y 与同一连续高度比较，用于视觉离地判定。桌面相机沿现有炮塔世界变换跟随，手机相机保持独立水平朝向。

0023 城堡 81（obj05449）的初始占用为服务端烘焙的 291 格。`art/hd/movement/0023.json`、`art/compressed/movement/0023.json` 和 `apps/web/public/data/maps/0023/movement.json` 使用相同数据。移动导出器直接复用烘焙地形及启用物件的占用格，默认导出到 HD 源目录，再经既有压缩及发布流程交付。

0003 蛋糕南路的桥入口低矮侧壁被站立棱柱误算为墙。`line736` 西端侧壁最高约 3.159，而入口 NAV 高度为 2；`line737` 西端侧壁最高约 2.901，入口 NAV 高度也为 2。共享地形占用现在遵从项目落脚限高 18，低于该限高的地形垂直侧壁不额外封路，场景物件仍使用原完整车身碰撞规则。

四座木桥导航由模型顶面精确投影修正 1,772 个格中心高度，其中补齐 258 个原无效通行格，保留其它字段字节；桥外新增通行格为 0。四个桥体分别为 `line712`、`line736`、`line737`、`line738`，只使用每个网格第一个分部的 6..13 号顶面三角形。服务端 NAV、HD 源、压缩数据和 Web 发布数据保持一致。

26 张地图中，14 张存在同类低矮地形误占用，共移除 1,846 个额外地形占用格。地形占用总数从 3,769 减为 1,923，物件占用格集合保持一致。原 NAV 禁行格继续禁行；木桥的通行补格独立限定于上述顶面。

资源导出顺序为原 NAV 导出 → NAV 同步及服务端碰撞烘焙 → 移动 JSON 导出。`assets:collision` 在烘焙完成后自动执行 `assets:movement`；`assets:battlefields` 单独负责 NAV 导出，完整 `assets` 链路按该依赖顺序执行。

## 地形模型对照

幽浮图可通行路段 `(860.298462, 115.042419)` → `(860.298462, 127.042419)` 的 NAV 高度为 `0` → `-1.484721`，HD 与怀旧 GLB 的 `plane04/0` 实际高度均为约 `-0.459091`，模型高度差小于 `0.000001`。这条路段的明显落差来自离散 NAV 高度，而显示模型在两点间近乎平坦。

对每张有完整足迹候选的地图，数据报告另保存最大高度差候选的源坐标、NAV 高度和同点烘焙地形三角面高度；三角面按距 NAV 高度最近的投影交点选择。0001、0003、0008、0010、0015 的所选候选模型高度差小于 `0.000001`，也存在模型平坦而 NAV 高度变化的路段。0016 当前所选候选由岸面通往桥板，模型与 NAV 的高度差均约为 3，对应实际桥板台阶。模型对照使用已保存的初始几何。

## 数据来源与范围

运行 `python3 tools/recovery/audit_ground_heights.py` 读取 `apps/web/public/data/maps/*/movement.json`、`apps/server/resources/assets/battlefields.json` 和 `scene-collision/*.json`。完整数值保存于 [map-ground-height-audit.json](../../recovery/output/map-ground-height-audit.json)，脚本只分析已有数据，不启动游戏或执行运动实现。木桥使用 `python3 tools/recovery/audit_bridge_navigation.py` 分析保存的模型和发布 NAV；`--map 0016` 分析仙剑岛秘密仙境的 12 座桥；`--original-navigation` 可指定原 NAV 层快照，记录修正范围。

本轮完成静态数据分析与源码处理，未编写单元测试，未运行测试、浏览器验收、构建、类型检查或原客户端实验。实际行走画面、不同朝向、临边姿态、帧率和原客户端垂直规则仍待独立实测；本记录不关闭 tasklist 中要求实测或原始来源的条目。
