# Shot显示的参数来源边界

完整`423956→489ba8`原执行证明：通知提供的XYZ逐float32原位转交世界效果接口`45afc2`，没有在这条显示链添加炮口水平30或高度20。192组覆盖普通槽的物件、管理器、所选技能、门禁、默认物件、默认技能存在性，以及三组XYZ；效果调用的三个坐标位值均与入口相同。此处坐标属于显示接口，不能据此声明它是权威弹丸出生点。

## 原调用链

`423956`从全局`633588→+128`取得技能系统，三个x87读写分别复制入口XYZ，再调用`489ba8`。后者的错误日志名称为`SYcSkillSystem::ShowShotEffect`。

普通槽路径先以2001查物件，再读取物件`+10c`作为技能表查找ID。完整原439b55载入器确认该偏移对应ItemSkill2；真实2001记录在此选择4020，原43abfd载入器确认技能Effect1/Sound1对应+70/+7c，即世界007/SE30。技能存在且`48603a`门禁返回0时，原分支把技能`+70`送入格式化入口`4880f0`；格式字符串在`5ca3d0`，内容为`_root\online\%03d`。随后调用世界效果接口`45afc2`，传入格式化名称、原XYZ和固定flag1。该flag调用原gbGfxManager::ClipPoint，只做裁剪，不改变XYZ或采样地形。技能`+7c`的字符串接着送入声音接口`4858f2`，enabled为1。此链的`+70`是世界效果名称的格式化输入；没有速度、寿命或轨迹赋值。

物件缺失或`635830→+60`管理器缺失直接结束。测试实际执行这些提前退出、所选技能成功和默认回退分支，核验每次返回位置与栈清理，以及成功分支物件/技能查找ID、效果字段偏移、管理器、XYZ、flag与声音参数。

普通物件2001及技能2001/4020的已导出原表仍见`projectile-source-sol.md`：现存item/skill列没有弹丸Velocity/Lifetime字段。本192组的`skill+70`夹具值0用于执行显示分支，不代表真实普通2001选择。实际列到字段映射及正式自由瞄准显示见[普通Shot世界显示](combat-shot.md)。

## 集成边界与限制

角色查询/普通槽getter、物件及技能表查找、技能门禁、字符串格式化及寿命、世界效果与声音末端由夹具提供。完整`423956`和`489ba8`的控制流、原字段读取、x87坐标复制及末端调用参数实际执行。所选技能缺失或48603a门禁返回非零时，489d4a调用43bdbd取得默认物件，再按其+10c查技能；默认物件或默认技能缺失时结束。回退技能不再次调用48603a门禁。两个独立技能记录分别设不同效果字段与声音地址，成功末端按被选记录取+70/+7c，XYZ仍透传。特殊槽的实例来源仍不在本192组内。

可集成的合同是显示坐标透传和物件到技能到世界效果/声音的选择；世界效果末端本身仍需按效果系统合同接入。本证据没有取得弹丸创建/更新函数、权威出生点、速度、寿命、轨迹或命中源。现有360单位/秒、30/20炮口和2.2秒仍保留原型标记，未新增弹丸参数纯函数。替换这些值需要另一个实际创建/更新入口，不能把显示坐标或视觉效果寿命作为替代证据。

回退选择验收记录：shot-display-fallback-native.log与projectile-parameters-sol-native.json。每组验证查询序列、门禁调用次数、回退次数、效果/声音选择、原XYZ位值与栈清理；此为完整原控制流执行，表lookup、默认物件getter及效果/声音末端由夹具供给。夹具默认物件Skill1设4020只用于区分记录，不能据此认定真实默认物件固定使用4020。
