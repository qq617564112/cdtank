# React 账户对局记录

对应任务：E-R03。正式界面为 `apps/web/src/interface/account/history.tsx`，样式沿用 `history.css`。`AccountHistoryView({open, close, source})` 由应用拥有开关；`AccountHistorySource.history(offset, limit)` 继续复用现有 Battle 账户查询。页面展示服务端确认的结算记录，属于重建账户界面。

## 交互与状态

每次打开挂载独立查询会话，查询首批 20 条。返回、Esc 和应用关闭会同步失活当前会话。服务端响应只有在会话仍有效、查询代次匹配时才提交；关闭重开或更换 source 后，旧响应不会修改新页面。同步 pending 标记阻止同一次提交期间的重复翻页、刷新请求。

上一页、下一页和刷新使用已确认页码；服务端返回的 offset、total 和 records 是页面唯一记录依据。请求期间保留已确认行和页码并禁用查询按钮，失败显示错误并恢复重试，初次空账户显示空态。记录保留中文时间、模式/地图、胜负/排名、击杀/死亡、目标、战斗与结算得分、结束原因以及原有全部 `data-history-*` 选择器。

原生 modal dialog 管理焦点范围和背景隔离；关闭恢复打开前焦点，请求完成在未转移焦点时恢复原查询按钮。页面停止键盘事件冒泡，继续采用现有自适应宽度、滚动表和分页换行样式；中文内容由 JSX 文本节点显示。

## 验收范围

本切片相关验收是正常账户打开、分页、刷新与失败保留、关闭重开迟到响应隔离、键盘关闭/焦点、1080p/4K，以及真实自然结算记录和账户重启恢复。页面不产生结算、修改分数或创建历史；相关自然对局和持久化证据由集成验收提供。本文不将组件实现或类型检查视为真实业务验收通过。
