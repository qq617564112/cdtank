# CPU 随机角色

新增 CPU 从原表 10 只宠物和 21 种战车分别随机选择，建立房间内独立角色实例。名字从60个候选中随机选择，统一追加`[bot]`，排除房间内已使用的名字；称号从现有称号目录随机选择。名字、称号、宠物、战车与迷彩在死亡复活和再战时保留，移除 CPU 后随房间成员释放。

宠物生命、凶猛与好运读取 pet；战车攻击、攻击加值、防御、防御加值与部件容量读取 tank。迷彩只选本车型实际存在的部件、`selectable`且所需纹理均已`resolved`的目录行；炮塔与车体按同名配色一起选择，履带从独立配色池选择。没有可选迷彩的车型105保留模型内嵌贴图。初始技能等级、战车剩余分钟和未装备槽采用普通新购角色的初值。当前原表所有战车的宠物类型与大小限制均为 0。

角色通过 bindOwnedBattleSources 接入玩家共用的生命、攻防、精通、弹药及移动重算。普通开火、命中、防御、暴击与复活继续使用同一业务入口；擒王生命沿既有模式规则。临时角色不写账户存档，不消耗房主资金；实例 1 和 9 与 CPU 道具槽实例 2–8 分离。

称号使用普通`PlayerTitle`快照显示，玩家账户称号刷新不覆盖CPU的房间内称号。此随机佩戴仅为机器人外观，不代表机器人满足账户称号的取得条件。普通玩家的称号取得和佩戴规则保持。
