# 移动端页面 UI

手机和平板共用横屏布局，沿用现有背景、木牌、卡片、面板、按钮与字体素材。战斗中的控制与 HUD 见[移动端战斗 UI](mobile-battle-ui.md)，显示偏好见[显示设置](display-settings.md)。

## 画布与比例

页面背景覆盖整个浏览器可见区域；内容先扣除刘海与手势条安全区，再使用 16:9 至 21:9 的可用范围。比例在此范围内时，内容随屏幕宽度展开；更宽或更窄的屏幕将内容居中，外围仍显示页面背景。竖屏沿用全局横屏提示。

登录、频道、大厅、加载、设置与游戏介绍使用 540 高的逻辑画布，宽度随实际比例在 960 至 1260 之间变化。账户页面使用 405 高的逻辑画布，宽度在 720 至 945 之间变化，使原有素材和控件在手机上获得更大的显示尺寸。手机结算直接按安全区的实际像素排版，使用双栏名单、固定底部操作和独立安排的颁奖及奖励区域；称号、装备通知也使用安全区尺寸重新安排内容。固定内容弹窗居中，缩放受安全区尺寸限制。电脑保留原有控件布局并居中显示。

公共实现位于 `apps/web/src/platform/page-viewport.ts`；手机使用布局视口 `document.documentElement.clientWidth/clientHeight`，窗口、屏幕方向和全屏状态变化在下一帧统一更新页面范围、逻辑宽度与缩放。视口声明使用 `interactive-widget=resizes-visual`，软键盘仅压缩可见视口，由浏览器平移可见区域以显示输入框，页面和弹窗保持原有缩放。页面及弹窗通过 `subscribeGamePageViewport` 接收通知，先更新公共 CSS 变量，再更新布局消费者。移动样式从 `apps/web/src/interface/mobile/mobile-pages.css` 统一导入。视口与软键盘行为见 [MDN VisualViewport](https://developer.mozilla.org/en-US/docs/Web/API/VisualViewport) 和 [Chrome 视口调整说明](https://developer.chrome.com/blog/viewport-resize-behavior)。

## 页面与操作

| 页面 | 移动布局与操作 |
| --- | --- |
| 登录 | 标志与入口木牌位于左侧，账户表单位于右侧；放大输入框、登录、注册与退出按钮 |
| 频道选择 | 列表按宽屏展开，放大表头与频道行；选择频道后使用“进入大厅”按钮 |
| 大厅 | 移除聊天框及聊天背景，房间区使用四列两行卡片；放大玩家列表、搜索入口和房间工具栏；单击房间加入，单击玩家查看资料 |
| 等待房间 | 放大原房间内容并居中；隐藏大厅社交侧栏；触摸成员槽打开详情与踢出操作 |
| 创建与编辑房间 | 地图、名称及密码和人数、时长及规则分为左右两栏；扩大输入、加减与确认操作 |
| 地图选择 | 放大模式标签、地图卡片、地图名称及翻页按钮 |
| 我的家与装备 | 放大列表、账户文字、属性及正文；库存与统计面板展开；长列表和说明支持触摸滚动 |
| 商店 | 放大商品与拥有物品列表；道具与零件商品使用两列；右侧购买区域展开，按钮文字放大 |
| 技能与改装 | 以实际内容框作为移动弹窗范围，放大内容和操作；技能正文可滚动 |
| 战车迷彩 | 将迷彩选项移至预览右侧，放大名称、箭头、费用及返回按钮 |
| 购买、出售、改名与房间密码 | 同步扩大背景框、提示区域、输入框及确定／取消按钮 |
| 玩家资料、搜索与交易 | 放大资料与列表文字；玩家搜索使用大输入框、可滚动结果与固定底部操作；交易候选项和数量操作放大 |
| 设置 | “画面与声音”和“键位设置”分栏切换；画面与声音使用两列大滑杆，键位列表单独显示 |
| 游戏介绍与历史记录 | 分类、正文及历史内容按横屏展开，正文与记录可触摸滚动 |
| 结算 | 双栏一屏显示全部名单，团队模式按队伍分栏，个人模式按排名均分；行高上限42 CSS像素，按人数和可用高度收缩，头像、文字和奖章随行高调整，行间距3像素。标题区高40、底栏高52，底部保留经验、等级和继续操作；颁奖演出、账户奖励与称号／装备通知分别按手机尺寸排版 |
| 加载、错误、GM 回复与退出页 | 加载内容按宽屏居中；错误详情和回复列表可滚动，退出后的重新进入按钮放大 |

我的家和商店的物品操作使用单击选择、连续两次短触激活、长按约半秒查看说明；滑动列表会收起说明。大厅房间与玩家使用单击直接打开；频道提供明确的进入按钮。桌面继续使用原有鼠标操作。

## 素材与验证范围

页面复用现有 UI 素材。地图选择、房间卡片及等待房间使用 `xiaoditu0` 图片集；其 50 张预览（含灰色版本）从 `art/compressed/ui/regions/76/` 合入大厅图集，清单兼容原逻辑路径及旧发布路径。预览保持 106 × 86，图集合并使用无损 WebP，两套战斗包不包含这些预览。

2026-10-13 使用 Chromium 148、Android 用户代理与触摸模拟，逐页检查以下横屏视口。检查包括截图目视检查、控件位置与遮挡检查，以及真实触摸事件执行的主要操作。

| 视口 | 比例 |
| --- | --- |
| 800 × 450 | 16:9 |
| 844 × 390 | 约 19.5:9 |
| 880 × 396 | 20:9 |
| 924 × 396 | 21:9 |

使用独立的临时账户数据库和两名检查账户。预置余额、成长值和 71 条库存，以检查长列表、各类物品及可学习技能；房间、购买、出售、装备保存、维修、改名、迷彩保存、技能学习、对局结算及历史记录通过实际服务端操作产生。

浏览器走查后修正了登录输入框与复选框定位、大厅工具栏遮挡、设置分类按钮尺寸、关闭按钮出屏、迷彩文字裁切及箭头尺寸、搜索分页被遮挡、交易文字与金额输入过小、装备类别和剩余天数拥挤、部件售价裁切、触摸说明妨碍连续短触，以及 GM 错误区挤出重试按钮等问题，并复查对应页面。

原始截图和各比例控件记录保存在本地临时目录 `/tmp/cdtank-mobile-ui-browser/`；`*-geometry.json` 与同名前缀 PNG 对应。加载错误、GM 回复、长名单结算和奖励通知的文件名含 `fixture`，用于区分受控组件状态与实际业务流程。奖励通知示例固定演出中的可见布局，没有触发账户奖励发放。

### 验证范围

本次为 Chromium 的浏览器触摸模拟，未进行真机、Safari、系统软键盘或刘海安全区实测。GM 回复组件当前没有生产入口，使用受控组件示例检查。未运行单元测试、构建或类型检查；既有战斗性能实测仍按原文档范围记录。

当前保留原版美术与演出的手机结算布局仅完成源码和尺寸静态核对，未运行新的测试、构建、类型检查或浏览器、真机验收。

布局视口下的软键盘弹出、收起及输入框避让仅完成源码走查，尚未进行浏览器或真机实测。
