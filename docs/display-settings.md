# 显示设置

登录页“系统设定”及游戏中的设置窗口共用显示、声音与键位偏好。音乐、音效、亮度、饱和度、对比度、渲染分辨率，以及动态模糊、卡通描边和 FPS 开关实时预览，点击确定后保存；取消、关闭或按 Esc 恢复未保存项的原值。“恢复默认”也会预览上述设置的默认值，确认前不写入存储。键位、窗口／全屏、抗锯齿和战斗素材在确认时应用。

## 显示选项

| 选项 | 范围与默认值 | 作用 |
| --- | --- | --- |
| 战斗素材 | 怀旧／HD，默认 HD | 切换战车、履带、宠物、饰品、地图物件、地面水面、环境模型和特效贴图；手机、平板和电脑均可选择；移动端 HD 贴图尺寸与怀旧版一致 |
| 渲染分辨率 | 0.25×、0.5×、1×、1.5×、2×，默认 1× | 调整战场主相机相对屏幕原生像素的 3D 渲染尺寸，HUD、名牌和小地图保留原画布分辨率 |
| 抗锯齿 | 4× MSAA，默认关闭 | 平滑几何边缘，增加渲染开销 |
| 动态模糊 | 默认关闭，位于抗锯齿下方，最多4次颜色采样 | 根据物体及镜头运动模糊战场画面；本地玩家坦克、炮塔及其模型饰品保持清晰，HUD、名牌和小地图保持清晰 |
| 卡通描边 | 默认开启 | 控制角色模型的卡通轮廓 |
| FPS 显示 | 默认关闭 | 显示约每秒更新的帧率、CPU 分段耗时、战场和输出 GPU 耗时、P95 帧间隔及绘制次数 |
| 亮度 | 0.5–1.5，默认 1 | 调整页面整体亮度 |
| 饱和度 | 0–2，默认 1 | 调整页面整体颜色饱和度 |
| 对比度 | 0.5–1.5，默认 1 | 调整页面整体对比度 |
| 窗口／全屏 | 使用浏览器全屏能力 | 确认时请求进入或退出全屏，按钮可用性由浏览器决定 |

渲染分辨率按宽、高分别缩放；0.5× 的 3D 像素量约为 1× 的四分之一，2× 约为四倍。UI 仍保留清晰度。素材选择与渲染分辨率分别控制贴图和画面像素数量，可独立组合。

手机、平板和电脑的战斗画布均适配设备像素比：画布宽高为 CSS 宽高乘以浏览器的 `devicePixelRatio`，战场 3D 目标再乘以设置中的倍率；HUD、名牌和小地图始终按原生画布分辨率绘制。没有已保存的设置时默认 1×，恢复默认也采用 1×，已保存的倍率继续按原值读取。例如 CSS 为 844×390、设备像素比为 3 时，画布为 2532×1170 像素；选择 1× 时 3D 目标为 2532×1170，选择 0.5× 时为 1266×585。拖动滑块立即预览倍率，点击确定保存，取消恢复原值；横竖屏、视口尺寸及设备像素比变化后按新的尺寸调整。

手机和平板关闭战斗实时阴影，不创建场景阴影方向光或阴影贴图；怀旧和 HD 两档贴图画质均采用无阴影路径。电脑端使用单层 1024×1024 阴影贴图，沿用各地图的方向光与各模型的软阴影设置；战车、地形、建筑和破坏模型使用统一场景受光与阴影。

战场后处理按所选倍率分配 3D 目标，再以双线性采样合成回原生画布，4× MSAA 按保存的设置应用。HUD、名牌和小地图在后处理之后绘制。独立模型预览沿用各自的画布策略，不读取战斗渲染倍率。

动态模糊使用 Babylon 官方 WebGPU/WGSL 几何缓冲提供线性运动矢量和对象标记，自定义后处理按屏幕位移选择1至4次颜色采样。本地玩家坦克、炮塔及其模型饰品通过深度测试后的对象标记排除；沿模糊方向采样时也跳过玩家区域。切换开关立即预览，无需重新加载；关闭时释放效果和几何缓冲，取消设置时恢复原来的开关状态。效果随战场分辨率调整尺寸，首次开启、窗口缩放和镜头突变时跳过一帧模糊。官方来源、帧率补偿及限制见[WebGPU 动态模糊](recovery/webgpu-motion-blur-research.md)。

手机和平板自动降低战斗特效密度：连续粒子发射率与粒子容量降至约一半，单次爆发数量减半并向上取整，单粒子的命中反馈保留；精灵拖尾保留约一半历史样本，采样间隔加倍；无伤害命中的烟团从三团减为中央一团。移动端怀旧与 HD 两档贴图画质使用相同的精简配置，预分配按减半后的粒子容量与拖尾上限准备缓冲。减少发生在粒子生成和拖尾记录阶段，同时降低模拟与绘制开销。命中闪光、爆炸主体、技能状态提示、特效尺寸和持续时间、音效及战斗时序沿用原参数。电脑端使用完整特效。

移动端复用结束后的世界精灵与粒子网格、材质及顶点缓冲，控制器切换时仅在实际渲染状态变化后更换资源；空闲缓存最多 64 组，同一节点和渲染状态最多保留两组。行驶烟尘、常规命中与爆炸、可破坏物烟尘及幽灵贴图在战斗加载阶段预分配缓冲并准备着色器。特效源树按不可变的资源表建立节点和控制器索引，精灵快照按固定字段复制，相机视图不变时复用逆矩阵，减少特效触发和播放期间的同步创建与临时对象开销。

移动端固定页面视口，阻止手动捏合、双击缩放与整页拖动、回弹；聊天和列表内部仍可滚动，摇杆、滚动条和模型预览保留各自的拖动操作。横屏策略覆盖全局页面，电脑端沿用浏览器的缩放与滚动行为。

移动页面支持 16:9 至 21:9 横屏，使用安全区内的可用宽度展开内容。手机大厅移除聊天框，单击房间加入、单击玩家查看资料；频道选择提供“进入大厅”按钮。背包和商城列表保留“点一下选中、连续点两下激活”：同一控件的两次短触点按间隔不超过 400 毫秒时执行原双击操作，拖动、滚动和长按不参与识别；电脑继续使用鼠标双击。页面覆盖与验证范围见[移动端页面 UI](mobile-pages-ui.md)。

## 战斗材质选择

客户端读取 `battle-artwork.json`，按选定画质将战斗资源 URL 映射到对应目录。手机、平板和电脑均提供怀旧／HD 选项，按同一个本地偏好键保存，默认 HD。怀旧使用 `assets/models/original/` 与 `assets/textures/original/`，保留原导出尺寸与 RGBA 像素。电脑 HD 使用 hd 目录中的 UV／显示用途压缩成品；移动端 HD 使用 mobile-hd 目录中的独立成品，从 `art/hd` 直接压缩，逐张尺寸与怀旧版一致。三份模型沿用相同几何、UV 与动画。

移动端两档画质与电脑怀旧的小地图底图使用 512×512 WebP，电脑 HD 使用 1024×1024；两者保持同一地图范围和坐标映射。移动端两档与电脑怀旧的小地图标记和边框采用一倍密度，电脑 HD 采用四倍密度。手机仅加载目标、VIP 和蓝红箭头，标记图集为 144×32，不加载电脑使用的车型俯视图标。

UI 与字形保持当前素材。商城、我的家等预览使用 HD 美术，移动端读取 mobile-hd 成品。没有原版对应项的补充素材沿用 HD 来源，生成清单记录其来源。生成命令与共用素材范围见[资产压缩与发布](asset-compression.md#怀旧与hd战斗素材)。

## 保存与重新加载

任一设备更改战斗素材或 4× MSAA 后，点击确定会保存偏好并重新加载客户端，使模型和引擎按新的配置创建。预览其它显示偏好不会应用尚未确认的 MSAA 草稿；FPS 显示与统计共用同一秒的采样。保存失败时保留面板与当前预览并提示重试，已经成功保存的项继续生效；取消仅恢复尚未保存的项。重新加载后的账户、频道和对局恢复沿用[路由与会话恢复](navigation.md)。

GPU 时间查询与回读仅在开启 FPS 显示时运行。CPU 为主场景与屏幕渲染层一次同步提交的平均耗时；GPU3D 为战场分辨率渲染目标最近一次返回的 GPU 耗时，GPUout 为最终画布合成、名牌、小地图等输出 pass 最近返回的 GPU 耗时；两者不包括浏览器 DOM 合成。P95 为这一秒内 95% 的帧间隔不超过的值。手机端 DOM 对局诊断状态最多每 100 毫秒发布一次，模拟、动画与交互继续逐帧更新。

第二行各 CPU 时间的单位为毫秒，按这一秒的渲染帧取平均：Update 从主场景开始到网格评估前，包含动画、战斗与特效更新；Mesh 为主场景网格评估；Draw 为主场景绘制提交；UI 为场景渲染后单独提交的屏幕图片层；Other 为其余同步场景工作，包含后处理及名牌、小地图渲染层；DC 为每帧绘制次数。Gap 为上一帧统计结束到下一帧渲染开始的平均间隔，包含引擎收尾、网络及 React 更新、浏览器布局合成、刷新率等待等，不能单独视为 CPU 工作时间。

第三行显示背景音乐的播放状态、曲目 ID、播放秒数、音量、静音标记和错误，每秒更新一次。可用于区分浏览器播放许可拒绝、解码失败和静音；具体状态见[资源加载](resource-loading.md#正常启动与按需载入)。

末行 `Resources` 每秒显示主场景资源数量：`Mesh` 为网格数，`Mat` 为材质数，`Dispose` 为场景销毁回调数，`BG` 为 WebGPU 全局查找缓存上次清空后累计创建的绑定组数组数，一组绘制配置计一次。临时特效播放时网格和材质可以增加，结束后释放或进入有界复用池；飘字结束后移除对应销毁回调。`BG` 达到 4096 次后在帧提交结束时归零，活动绘制上下文仍保留各自的绑定组；此数包含同页面其他 WebGPU 模型预览引擎的创建。

| 本地存储键 | 内容 |
| --- | --- |
| `cdtank.display-settings.v1` | 渲染分辨率、描边、MSAA、动态模糊和 FPS |
| `cdtank.audio-settings.v1` | 音乐与音效音量 |
| `cdtank.battle-artwork.v1` | 怀旧或 HD |
| `cdtank.brightness.v1` | 亮度 |
| `cdtank.saturation.v1` | 饱和度 |
| `cdtank.contrast.v1` | 对比度 |

这些设置按浏览器和站点保存，不写入账户数据库，也不进入服务器账户备份。全屏状态由浏览器管理；切换浏览器或清除站点数据后重新设置。

## 限制

客户端与模型预览要求支持 WebGPU 的浏览器，并通过 HTTPS 或 localhost 访问。房间恢复受 30 秒断线窗口限制，重新加载超过窗口后需重新加入。怀旧／HD 切换及后续场景软阴影尚无完整游戏内视觉和性能验收；已有数据范围见[浏览器性能](browser-performance.md)。
