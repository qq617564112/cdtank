# 显示设置

登录页“系统设定”及游戏中的设置窗口共用显示、声音与键位偏好。修改先保留为草稿，点击确定后保存；取消放弃草稿。“恢复默认”填回默认草稿，点击确定后生效。

## 显示选项

| 选项 | 范围与默认值 | 作用 |
| --- | --- | --- |
| 战斗素材 | 怀旧／HD，默认 HD | 切换战车、履带、宠物、饰品、地图物件、地面水面、环境模型和特效贴图 |
| 渲染分辨率 | 0.25×、0.5×、1×、1.5×、2×，默认 1× | 调整战场主相机的 3D 渲染尺寸；HUD、名牌和小地图继续使用原画布分辨率 |
| 抗锯齿 | 4× MSAA，默认关闭 | 平滑几何边缘，增加渲染开销 |
| 卡通描边 | 默认开启 | 控制角色模型的卡通轮廓 |
| FPS 显示 | 默认关闭 | 显示约每秒更新的帧率 |
| 亮度 | 0.5–1.5，默认 1 | 调整页面整体亮度 |
| 饱和度 | 0–2，默认 1 | 调整页面整体颜色饱和度 |
| 对比度 | 0.5–1.5，默认 1 | 调整页面整体对比度 |
| 窗口／全屏 | 使用浏览器全屏能力 | 确认时请求进入或退出全屏，按钮可用性由浏览器决定 |

渲染分辨率按宽、高分别缩放；0.5× 的 3D 像素量约为 1× 的四分之一，2× 约为四倍。UI 仍保留清晰度。素材选择与渲染分辨率分别控制贴图和画面像素数量，可独立组合。

## 怀旧与 HD 素材

客户端读取 `battle-artwork.json`，按选定画质将战斗资源 URL 映射到 `battle-artwork/original/` 或 `battle-artwork/hd/`。怀旧贴图保留原导出尺寸与 RGBA 像素；HD 使用按 UV 或显示用途压缩后的成品。两套模型沿用相同几何、UV 与动画。

UI、字形、涂鸦小地图，以及商城、我的家等预览保持当前素材。没有原版对应项的补充素材由两种画质共用，生成清单记录其来源。生成命令与共用素材范围见[资产压缩与发布](asset-compression.md#怀旧与hd战斗素材)。

## 保存与重新加载

更改战斗素材或 4× MSAA 后，点击确定会保存偏好并重新加载客户端，使模型和引擎按新的配置创建。其余显示偏好确认后应用；FPS 显示与统计共用同一秒的采样。重新加载后的账户、频道和对局恢复沿用[路由与会话恢复](navigation.md)。

| 本地存储键 | 内容 |
| --- | --- |
| `cdtank.display-settings.v1` | 渲染分辨率、描边、MSAA 和 FPS |
| `cdtank.battle-artwork.v1` | 怀旧或 HD |
| `cdtank.brightness.v1` | 亮度 |
| `cdtank.saturation.v1` | 饱和度 |
| `cdtank.contrast.v1` | 对比度 |

这些设置按浏览器和站点保存，不写入账户数据库，也不进入服务器账户备份。全屏状态由浏览器管理；切换浏览器或清除站点数据后重新设置。

## 限制

客户端与模型预览要求支持 WebGPU 的浏览器，并通过 HTTPS 或 localhost 访问。房间恢复受 30 秒断线窗口限制，重新加载超过窗口后需重新加入。怀旧／HD 切换及后续场景软阴影尚无完整游戏内视觉和性能验收；已有数据范围见[浏览器性能](browser-performance.md)。
