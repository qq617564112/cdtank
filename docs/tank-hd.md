# 坦克高清素材

21 辆坦克的现存车身、炮塔和主题皮肤使用原生高清重绘；模型几何、UV、原有黑色面板线与简单卡通风格保留。全部履带使用完整轮子旋转与闭合链带推进，颜色变体共用动画图集。

## 覆盖范围

| 内容 | 数量 |
| --- | ---: |
| 坦克 | 21 |
| 现存主题皮肤组合 | 323 |
| 车身图集 M | 323 |
| 炮塔图集 U | 195 |
| 原有履带 A/B 图集 | 162 |
| 新增履带动画图集 | 74 |
| 各坦克动画帧合计 | 116 |
| 履带颜色记录 | 81 |

151–158 没有独立炮塔模型，主题皮肤仅使用 M。105 保留三套有效主题皮肤和一种履带颜色；其它坦克各有 16 套主题皮肤和四种履带颜色。

M/U 图集共 518 张：502 张为 4096 × 4096，16 张为 4096 × 2048。长方形图集保持原始宽高比例；001 默认 M/U 同为 4096 × 4096。UV 对齐在 4K 输出分辨率内重采样。以原图绘画轮廓配准高清图集，保留内部面板及皮肤图案；颜色采样边覆盖模型 UV，避免留白进入模型面。履带图集为 1280 × 1280。

10 辆使用五帧，11 辆使用六帧；六帧用于五辐轮等结构，轮子整体旋转且轮心固定。运行帧间隔为 0.04 秒。前进和倒车分别顺序、逆序播放；原地转向时两侧反向播放；停车保持当前相位。

## 文件与发布

`art/hd/` 按运行相对路径保存高清源图，`manifest.json` 包含原图与高清图对应关系，`tank-track-animations.json` 保存帧路径、帧间隔及全部颜色记录的 RGB 滤镜。原版输入保存在 `art/original/`。

上述 4K 尺寸属于源图。当前运行贴图经[压缩配方](asset-compression.md)一次缩放到长边 1600 并编码为 WebP，再发布到 public；模型默认 Data 路径、可选皮肤和履带配置同步。`assets:battle-artwork` 同时发布原尺寸怀旧版、电脑压缩 HD 版和 compressed-mobile 生成的移动端 HD 版，移动端两档贴图尺寸一致；UI 保持既有素材，模型预览使用 HD 美术并在移动端读取缩小成品。

按[运行美术资源](original-assets.md)准备基础资源和履带配置，再生成 compressed 及怀旧与 HD 两套战斗资源。动画帧由履带配置引用。美术资源由 Git 忽略，发布资源包时包含最终图片、模型与配置。

## 素材预览

M/U 的逐图来源与元数据位于 `output/imagegen/tank-api4k/`，全部 323 套皮肤的原版/API 六视角 PNG 位于各车型的 `renders/`，共 3876 张。模型预览在均匀环境光、无点光源条件下完成。

履带及其它预览目录为 `output/tank-hd/`：

- `tanks.png`：21 辆默认坦克总览。
- `materials.png`、`skins-detail.png`：默认材质与主题皮肤细节。
- `coverage.json`：逐图路径、尺寸、默认引用与各坦克皮肤覆盖清单。
- `<id>/default-*.png`：默认六视图及完整坦克主视图。
- `<id>/skins.png`、`<id>/skins/`：全部 323 套实际有效皮肤组合。
- `<id>/track-*.webp`：前进、倒车、原地左右转及停车素材。
- `<id>/track-colors.png`：该坦克全部履带颜色。
- `prompts/`、各坦克 `uv.json`、履带布局和复用分组：制作提示词与材质布局参数。

预览使用游戏的 `TankView`、MV3 材质和 `SceneActorToon`，按运行配置显式推进履带；相机固定，模型姿态一致。WebP 预览每帧 120 毫秒，便于查看运动；运行配置仍为 40 毫秒。制作参考与预览均位于 public 之外。

## 限制

验收范围为实际游戏材质下的坦克素材渲染，未进行完整游戏流程或浏览器验收。未运行测试、构建或类型检查。履带侧面原有分档光照暗带保留。
