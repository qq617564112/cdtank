# 出生与复活选点

全部25张原地图与测试地图共用同一选点实现，人数遵守各地图及房间已有上限。首次开始与再战先恢复本局场景障碍碰撞，再安排出生；全部位置安排成功后才进入PLAYING。

出生组统一选择NAV有效且高度与源值相符的非零点较多的一组。两组数量相同时，团队模式优先第一组，混战与破坏优先第二组；第二组为空的地图继续使用第一组。保留所有组与原槽号，不以压缩后的下标重新解释队伍。

地图明确记录队伍时使用其队伍标记；第一组完整两侧分别使用槽位1–6和7–12。散布型第二组或缺失一侧的点集按主要空间轴划分两侧，每侧沿另一轴排序。补点保持在所属侧的地图区域。

团队、占领与擒王模式按双方实际人数分别安排，各队只使用自己一侧，支持双方人数不等。混战与破坏模式按总人数分到两侧，奇数人数先取一侧多一人；源点总数充足但两侧数量不等时，将超出一侧容量的人数分给另一侧。每侧沿有序点集等间隔取点，包含两端，每侧只有一人时取首点。

源点不足时不重复分配同一槽位。后续玩家的可用源点会提前保留；受阻的位置先在所选点附近寻找可用地面，再选择该侧其它源点。没有预选源点的玩家优先填补与已安排玩家及保留位置相距最远的空位。附近仍不足时搜索该侧实际NAV格心，先按60单位步长搜索，无可用点时细化到12单位。开局同队至少间隔60单位，敌对玩家至少180单位，并检查车身碰撞；混战所有其它玩家均视为敌对玩家。

复活安全性只比较仍存活的其它坦克，并优先避开本人死亡位置与上次成功复活位置的180单位邻域：

- 混战与破坏模式选择离最近对手最远的可用点。
- 团队模式有存活队友时，先筛选安全且避开近期位置的可用点，再优先靠近最近队友；等距时选择离敌人更远的位置。明确带队伍标记的地图仍遵守该标记。
- 没有存活队友时，优先使用本队所在一侧，并选择离敌人最远的位置。

选点检查完整49×52车身对应的NAV地面与存活坦克碰撞。安全点须与敌人至少间隔180个原坐标单位，并通过正式射击目标查询：假定每个存活敌人转向该点，使用其普通弹药及当前弹药、射程修正与穿透规则，检查当前地形和场景碰撞；不将其它坦克的临时挡枪视为安全掩体。源点没有安全且避开近期位置的候选时，加入周围60、120、180单位的候选位置，仍不足时搜索实际NAV格心。没有队友时的团队复活及带明确队伍标记的地图，补点继续遵守本队区域；其它团队复活可在地图中靠近队友选择。没有安全替代点时可复用现有安全点；完全没有安全点时，优先在避开近期位置的候选中取离最近敌人最远的位置，没有替代位置则允许复用。没有可用位置则保持死亡，后续tick继续尝试。成功复活才更新上次位置，新局及再战清空该记录。死亡坦克和上一局坐标不参与新局开局安排。

上述槽位分侧、均匀取点、近友远敌与避战避重复规则为项目采用政策。原出生数组用途与原服务端选点规则尚未还原。本次未运行测试、浏览器验收、构建或类型检查。
