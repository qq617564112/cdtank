# 游戏操作提示

需要提醒玩家的操作反馈、成功和错误消息统一由 `GameMessage` 展示。木牌使用金色边框、浅色纸面、游戏字体和状态徽章，固定在视口右上方。

页面和资源准备、会话自动恢复、商城目录、玩家资料与列表、家族资料、昵称、迷彩目录和对局记录的正常读取保持静默。准备、换队、添加机器人、创建和保存、购买和出售、学习技能、发送聊天等操作的提交和等待过程也保持静默，由控件禁用状态和 `aria-busy` 表达。页面打开时的操作说明、正常资料数量和家族名称不发布弹出消息；内容数量显示在对应页面中。错误、操作结果和需要玩家处理的未确认状态仍发布消息。

每条消息从右侧滑入 200ms，完整停留 1000ms，再向上移出 240ms。连续消息按发布顺序展示，相同的待展示正文合并。已发布的消息由全局展示层计时，页面更新、请求结束或关闭操作窗口不会缩短其停留时间。系统设置为减少动态效果时使用同样时长的淡入淡出。

`GameMessageHost` 在游戏页面的根入口挂载一次。展示层使用手动 popover 进入浏览器顶层，显示在原生对话框上方。新对话框打开时，展示层重新提升并保持当前动画进度和计时，不接收鼠标事件，不转移键盘焦点。

状态驱动的页面使用公共组件：

```tsx
<GameMessage text={error} tone="error"/>
```

直接由操作结果产生的消息使用同一队列：

```ts
showGameMessage('战车迷彩已保存', 'success');
```

`tone` 支持 `info`、`pending`、`success` 和 `error`。空正文不发布消息。带 `open` 或 `visible` 的常驻页面只在对应页面打开时传入正文。

创建和编辑房间、等待房间、聊天、邀请与出售确认、商城、迷彩、保养、昵称、技能与改装、资料查询、设置、登录频道、退出和结算、资源错误均使用公共提示。资源失败后的返回、关闭和重试按钮保留在操作页面，使用公共游戏按钮。

启动和对局 loading 页的阻断错误由 `LoadingErrorDialog` 使用公共 `GameDialog` 居中展示，保留完整错误和重新载入按钮。弹窗与 loading 页共用 800×600 的界面缩放比例，窗口放大时边框、文字和按钮同步放大。弹窗不计时退出，Escape 和点击遮罩不会关闭；重新载入清除错误或离开 loading 页后关闭。
