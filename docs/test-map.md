# 测试地图

地图 ID 为 `1001`，开放团队模式，2–8 人，时限 300 秒。创建房间或编辑等待房间时，在团队模式的地图列表中选择“测试地图”。

地图采用 13×10 格布局，每格 96 个原坐标单位，保留参考图中的顶部墙阵、两侧竖墙、中段双横墙、两个木箱及底部折角墙。中央和侧翼通道宽度至少一格。两队各有四个出生点，开局、再战及重生按当前队伍选择出生区。

| 内容 | 复用资产 |
| --- | --- |
| 沙土地面 | `Data/map/0014/tiandi.png` |
| 金属墙块 | `obj05424` 箱体几何、地图 18 的 `dimian01.png` 金属贴图 |
| 砖墙块 | `obj05424` 箱体几何、`obj05443` 红瓦贴图与破坏动画 |
| 木箱 | `obj05424` 原模型、贴图及破坏动画 |
| 边缘草丛 | `obj05413` 原植物模型和贴图，交叉放置 |
| 战场音乐 | 田野路团队模式的 `GAM02` |

金属墙保留实体碰撞；砖墙和木箱使用既有场景物件伤害、破坏、掉落及再战恢复流程。客户端运动数据与服务端碰撞从相同的放置模型生成，CPU 使用同一导航网格。

布局及资源引用保存在 `apps/shared/maps/test-map.ts`。修改后运行：

```bash
npm run assets:custom-maps
```

生成器将场景、导航、运动数据、音乐映射及地图选择缩略图写入已安装的运行资源目录。`assets:install` 和完整 `assets` 导出也会生成地图；下载资源包和原版数据表保持原内容。

生成的地形、墙块模型与缩略图位于 `recovery/output/web-assets/custom-maps/1001/`。服务端在启动时读取地图目录，生成后需重启已有服务端；已打开的客户端重新载入即可取得更新的资源目录。
