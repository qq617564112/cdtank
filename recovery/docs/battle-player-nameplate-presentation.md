# Battle Player Nameplate Presentation

World nameplates are a non-interactive DOM overlay owned by `BattlePlayers`. The overlay shows teammates and opponents while alive during `PLAYING`; the current main-repository policy hides the local player's own label, and this reconstruction keeps that policy. Dead players, role disguise actors, and hostile optical-camouflage actors stay hidden. Modes 1-3 use the local snapshot team to color teammates as friends and other players as opponents; modes 4 and 5 treat all other players as opponents.

Each label uses authoritative `PlayerSnapshot.name`, `hp`, and `maxHp`, with current/maximum HP printed below the proportional health bar. The title row uses the equipped `PlayerSnapshot.title.name` wiring (`HudPlayer.title` reads `player.title?.name` in `battle-hud.ts`; account ownership and selection are persisted per UI-39), falling back to the requested original title table ID 1 `嗷嗷待哺` only when no worn title is present. The name row adds the original 22×12 VIP badge (77/136) only for mode3 VIP players. The projected anchor comes from the loaded `TankView.root.position` and the actual model hierarchy bounds, so the DOM overlay follows the rendered actor transform already used by the scene. Projection uses the Babylon camera transformation and render viewport, then maps render pixels to the canvas `getBoundingClientRect()` CSS surface. No screen X reflection is applied to the nameplate source position.

Labels are 112 source pixels wide and 44 source pixels high, arranged as title, name/VIP badge, health bar and numeric HP. The numeric HP is a same-layer successor row after the bar, so the box height is the source 44px (12 title + 2 + 14 name row + 4 bar + 1 + 11 numeric HP) and the bottom anchor no longer overlaps the model. They scale with the canvas against the 800x600 source viewport. Other players additionally scale by the square root of local-camera distance divided by their camera distance, clamped to0.82–1.10 for readability. A five-source-pixel screen gap keeps the text above the actual model top, and viewport edges keep visible labels readable. Text uses `CDTank-Xiangjiao`; the 96×4 health bar reuses original `wanjiaxuecao.tga` and `wanjiaxuecao_jindukuai.tga` regions 77/127 and 77/128, tinting the original fill outline green for friends and red for opponents. Current/maximum HP appears below the bar. Styles load with the renderer. The layer has `pointer-events: none` and sits below the source HUD layer, so it does not consume mouse or keyboard input. Round reset, player departure, room leave, and scene disposal remove stale labels.

## Limitations

The default title does not assign account ownership or selection; a real worn title is preferred, and the fallback text is presentation-only. The ordinary snapshot supplies an optional equipped title and no medal field is consumed here. The layout, anchors, mild distance scaling and existing observer visibility policy follow the user-confirmed beauty-first reconstruction of the original style. `isVIP` remains a separate snapshot/HUD property. The original native world-label font, exact height, and pixel policy remain unrecovered. The current DOM layout has not received browser, HD, or original-pixel acceptance; tests, builds, and type checks were not run for this change.
