# 交易整页交付提案

UI-60/61/62/63。原 trade.xml 根615×403，148控件；部件、宠物、坦克详情分别6/47/52控件。trade-page-source-proposal.json 保存全部原控件、父链累计坐标、图片引用与当前DDS优先图集映射。原加载入口4fd940、4fed2f、4feeba、4ffa40经loadWindowLayout5c0258分别存同owner+8/+344/+358/+3d4；仅静态指令依据，未执行原交易流程。

整页主要区域包括左侧三拥有名单、余额与数量，两方姓名和交易状态、双向提供物区域、金钱输入入口，以及展示、交换、取消和关闭控件。详情子页必须跟随真实选择及交易会话挂载。沿共享原800×600显示基准；根最终附着、居中与详情切换尚需原caller依据，不能从当前重建弹窗推断。

正式玩家资料的btnExchange目前禁用且无handler。现协议目录没有交易session接口；Inventory与OwnedRoles虽能读取自己的真实拥有记录，但没有对方提供物、双方展示/确认状态或所有权结算合同。不能把这两种只读记录呈现冒称普通玩家交易，也不能借商城BUY/SELL作为交换动作。

后续文件归属提案：UI owns新trade-source-page.tsx/css及三个详情消费者、原布局映射和专属只读/业务验收；root owns玩家资料的真实入口、两方session与authoritative状态合同及集成。现有player-info.tsx与共享协议均保持未修改。来源整理可独立使用；正式组件应在入口及状态合同足够后接入，不发布无法操作的临时外壳。

验收覆盖普通玩家发起、对方接受/拒绝、两侧拥有名单与提供物变化、展示/确认状态、取消/关闭后恢复原玩家资料焦点、中文金额输入及非法状态反馈；按真实业务合同确认结算或拒绝后拥有记录一致。完整800/1920/3840图须覆盖主要区域、文字、层级、名单滚动和详情切换。当前没有相应actual证据，四个页面父项均保持未完成。

限制：交易callback、listfactory、原根附着与缩放、金额字段语义及事务资格未证；本提案仅source/module边界准备，无生产写入、Chrome、类型或交易执行。
