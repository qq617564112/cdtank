# 角色战斗步进模块

E-02将每个角色的定时器、复活到期调用、CPU/托管输入、移动/转向/瞄准和装填射击循环收拢到battle/actors.ts。它在实际权威房间玩家上操作，不复制玩家或建立第二个模拟循环。CPU控制器生成的普通输入通过World.updateInput回调执行身份、阶段、序号和快捷槽授权。

World提供生命上限策略、复活提交、输入授权和弹丸编号；actor模块处理现有步进顺序与参数，并使用battle/projectiles实际创建弹丸。死亡角色先推进定时器，复活后本步仍跳过移动；原装填相对时钟和float32期限、完整拥有非VIP默认弹药来源、缺来源/特殊弹药的原型时长保持原样。房间到期检查仍在整个模拟之前，随后依次推进角色、弹丸、玩法目标。World现844行。

该迁移保留当前移动尺度和CPU重建策略，原移动字段/特殊弹药/VIP及权威伤害仍按M2恢复。验收使用正式World和普通输入：原完整属性/21战车装填生命、原场景碰撞/移动/弹丸/复活、自然治疗与数量保存、五模式准备/终局冻结/再战、自由瞄准，以及编译真实账户/迷彩重启和CPU五模式各两局。构建、类型和运行依赖边界检查确保新模块接入正式入口。

以上迁移验收全部通过，运行依赖覆盖184模块。证据为engineering-actors-{build,attributes,terrain,healing,match,free-aim,compiled,types,boundaries}.log。没有新增客户端渲染结论，资源表现仍按E-03与M3/M4/M7专题检查。
