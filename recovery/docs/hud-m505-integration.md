# 完整战斗 HUD 与五模式面板

目标：将 `game_main.xml` 的 165 个控件接入正式战斗页面，恢复八槽状态、头像与生命、小地图、五模式数字和聊天显隐，并明确原资源事实与当前服务端业务映射。M5-04、M5-05、UI-09 的完整验收以实际页面和原版视觉证据为准。

## 状态与生命周期

`BattleHud` 分别发布主 HUD、装填、战斗槽和小地图快照。主 HUD 包含房间、局号和阶段，移动坐标只进入小地图快照；快照内容相同不重复通知。离房清空数字、弹槽、效果期限、消息、复活倒计时和地图标记。等待阶段隐藏整棵战斗 HUD，下一局重新创建头像状态并清除上一局消息和模式计时。

`beforeShot` 与后续 `fire` 合并为一次头像开火表情；只发 `fire` 的服务端仍可触发表情。受击、死亡、复活与击毁保留既有头像状态机。伤害、治疗和暴击的原数字图片继续由原渲染器负责。

## 五模式数值

| 模式 | 原数字控件 | 当前权威输入 | 显示规则 |
| --- | --- | --- | --- |
| 团队 | `txtSelfInfo` / `txtEnemyInfo` | `match.teamLives` | 按本机队伍映射双方剩余生命 |
| 占领 | `txtSelfInfo` / `txtEnemyInfo` | `teamScores` | 按本机队伍映射双方占领分，按原整数显示截断 |

## 弹槽与小地图

鼠标点击第一至第四槽选择弹药，第五至第八槽立即使用或放置当前道具。透明按钮保持原框/图标/数量/遮罩，鼠标操作保留战斗输入焦点，键盘可操作；死亡、非PLAYING、托管或缺绑定时不可用。动作复用既有数字键输入与服务端分派，拒绝不本地扣量或选中。

默认 `2001` 炮弹供给显示原 Cheap 字体的无限符号 `ui/regions/2/0.png`。有限弹匣另由 `prgBullet` 显示，原消费者宽度为 `capacity × 15`，进度为 `remaining / capacity`。特殊弹槽优先使用权威 `ammoSlots`；道具槽数量读取已确认 Inventory。选中弹槽由 `selectedAmmoSlot` 决定，使用金色 Web 选中框，装填仅覆盖当前有效弹槽；道具效果期限以遮罩与剩余秒数表示效果仍有效，不提供新使用资格或本地扣量。

小地图保留源矩形 `(608,408)–(800,600)`、192×192与八边框。25图分别读取原NAV及RPT，形成包含全部出生点的固定正方形窗口；原场景俯视底图与快照标记共用 `u=(x-minX)/(maxX-minX)`、`v=(maxZ-z)/(maxZ-minZ)`，原朝上箭头按 `yaw` 旋转。范围及600个原出生点的像素映射见 `hud-minimap-coordinate-source.md` 和 `hud-minimap-map-mappings.json`。本机使用 `wotanke.tga`，其它坦克使用 `danke.tga` 的原轮廓并按敌我着色，目标使用 `diaobao.tga`；擒王的王附加 `viptanke.tga`。敌方有效光学迷彩沿共享观察者规则过滤。

完整主树、八槽、小地图与退出分别拥有121、41、2、1个原控件，合计165。五模式另有30个原控件。房间快照入口同步HUD阶段，WAITING/LOADING期间隐藏战斗HUD，PLAYING显示，FINISHED保留终值。开局先显示模式原图2秒，再显示Fight原图1秒，随后收起；这套时长与阶段策略已由用户确认采用。个人模式侧栏先列本人，再列所有其它对手，不按内部team字段归为队友。

世界标签包含本人、队友与敌方的权威选用称号（缺值默认“嗷嗷待哺”）、姓名、擒王标记和当前/最大生命；血条复用 `wanjiaxuecao.tga` 与 `wanjiaxuecao_jindukuai.tga` 的96×4原素材，沿实际坦克插值位置与模型顶边投影，并按观察距离温和缩放。详见 `battle-player-nameplate-presentation.md`。

聊天闲置时隐藏且不捕获输入；Enter 打开编辑，确认发送后关闭并返回战斗焦点，失败保留编辑与草稿。新消息显示五秒后经过 400 毫秒半透明模糊淡出。等待房间保持原常显聊天。
