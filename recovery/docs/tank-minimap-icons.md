# 坦克小地图图标

全部21种坦克使用真实三维模型重新生成64×64俯视PNG，每种提供本人白色、敌方红色、友方蓝色三种3像素外轮廓，共63张。小地图以玩家当前加载模型的 `tankId` 取图；模型尚未载入时使用权威快照的 `tankId`。本人使用白色，团队模式同队使用蓝色，其它玩家使用红色。

## 生成

准备项目依赖、Python3及Pillow、`recovery/output/web-assets/` 和 `recovery/output/verified/tables/tankshop.json`，在仓库根目录执行：

```sh
node scripts/render-tank-minimap-icons.mjs
```

脚本自行启动独立Vite渲染页面及无头Chromium，从 `tanks.json` 读取全部坦克，通过 `TankView.loadPreview` 装配真实模型与原 `tankshop` 默认U/M/XY贴图。浏览器路径可用 `CDTANK_CHROME` 指定，资源目录可用 `CDTANK_WEB_ASSETS` 指定。结束后关闭本次渲染器，清理临时目录。

渲染规则：

- 正上方正交俯视，炮口朝上，透明背景，固定静止动作首帧。
- 13种有U动作的坦克，将独立炮塔及炮管按原炮塔轴心等比放大到1.5倍；151–158这8种固定炮塔坦克按整体处理，等比放大后统一取景。
- 2048×2048渲染后缩小为1024×1024中间图，再裁取可见模型并保留轮廓空间。
- 沿用已确认的小勇士图标处理：8倍采样合成3像素外轮廓，再以Lanczos缩小到64×64。外轮廓分别为RGB(255,255,255)、RGB(255,80,80)、RGB(80,160,255)，模型贴图保留原色。

最终资源位于 `apps/web/src/assets/tanks/minimap-icons/`，通过源码索引随前端发布；现有源码图片预加载器包含全部63张图。中间图位于 `recovery/output/tank-minimap-renders/`，总览为 `recovery/output/tank-minimap-icons-overview.png`。

## 小地图接入

`BattleMinimapRenderer` 用三色坦克图标替换本人和其它玩家的箭头。图标、目标和王徽章合入1024×512透明图集，保留地形与标记两批GPU绘制。64×64图标在800×600基准画面中，本人显示为26×26、其它玩家24×24，并随HUD缩放。

所有坦克，包括本人，按实际车身朝向相对于相机水平轴的方向旋转。本人保持雷达中心；其它玩家按实时模型位置投影，模型缺席时读取快照坐标。超出显示范围的标记保持方位，中心固定在黑色边框内侧白色细边框的中线（基准半径89.5像素），不再减去图标半径。标记不受小地图圆形裁剪，允许向圆外溢出一半；王徽章显示在坦克图标上方。死亡、光学迷彩、雷达干扰和探测规则继续由既有权威状态控制。

已完成全部资源生成、静态总览查看及资源覆盖/尺寸核对。实际对局图标与方向、完整HUD验收保持开放；按仓库要求未运行测试、构建、类型检查或游戏浏览器验收。
