# 原地图联机与碰撞

## 恢复数据

`recovery/export_battlefields.py` 导出25张地图的218,704个POL三角形、2,058个虚拟盒体与600个出生槽位到 `recovery/output/web-assets/battlefields.json`。地形顶点、盒体矩阵和尺寸均使用原始单位；客户端在显示时反射X，服务端使用原坐标。

盒体矩阵平移指向几何中心。对全部2,058条记录，用独立position加矩阵旋转后的shapeMatrix局部平移核对中心，最大误差0.000121。局部矩阵均为单位旋转、Y轴平移半个高度。5个盒体具有零宽或零深度，保留为平面障碍。

原EXE `.rpt`字符串位于VA 0x5c71fc，加载引用0x45ba3b，文件读取调用0x45ba87 → 0x45e029。0x45e029读取u32标记；2005102301（0x77836edd）路径连续读取两个0xc0字节块。构造器0x45e3a9分别分配两个12槽数组，槽位大小16字节。旧标记2005092201（0x77834769）路径每槽只读取12字节；当前25份文件均为新标记及388字节。导出保留两个数组及每槽4个f32观察值，不改动源文件。

## 联机运行

`apps/server/src/battlefield.ts`按128单位网格索引地形三角形。视觉地形高度查询使用X/Z重心插值。移动使用原NAV单元高度与低字节有效性，轨迹跨过无效格子时停止，跨越过高的高度差时拒绝移动。原位置/中心换算依据见 `navigation-format.md`。虚拟盒体采用原正交矩阵，把运动线段变换至盒体局部空间，再作连续线段/包围盒求交；战车半径扩展盒体尺寸。

弹丸以整段轨迹查询盒体和原地形三角形，取最近交点，并与玩家球体求交结果比较；障碍在玩家前面时阻挡伤害。炮口生成前也查询车体中心到炮口的线段。原地图可阻止战车穿墙及弹丸跨越薄墙，移除了原型平面场地的固定260单位边界。

地形射线候选只取线段实际穿过的128单位网格，先以二维线段／网格闭区间求交排除外接矩形内不相交的格子，边界保守保留。三角形边向量在读取地图时缓存，求交保留原算术顺序与阈值，用标量计算消除每次方向／叉积／点积数组分配。盒体查询、地形源顶点及最终最近交点规则不变。该优化同时用于CPU视线、射击站位与实际弹丸。

`apps/web/src/battle.ts`依据Join返回的mapId载入地形、静态物件及城堡。战车以原模型尺寸显示，人物和弹丸的X及人物yaw在显示端反射；地图和玩家共用原始单位。相机从上方跟随本地玩家。返回时移除地图、玩家和弹丸。

## 验证

- `tests/navigation.cts`核对全部1,417,662个原NAV格子的中心、下标、高度和有效性，以及越界、斜穿无效格和视觉地面/NAV有效区域的区别。
- `tests/battlefield-source.py`逐点核对全部25张地图的三角形、600个出生槽位原字节及2,058个盒体矩阵/尺寸。
- `tests/battlefield.cts`核对全部原盒体的旋转及扫掠碰撞，包括5个零厚度盒体；通过原田野路出生位置驱动World移动与射击，验证障碍阻挡、地形交点及弹丸移除。另用模拟时钟验证原地图上的玩家命中、死亡、击杀归属与重生至恢复位置。
- `tests/surface-query.cts`在全部25张源地图对照1213条射线，独立参考实现遍历全部源三角形并保留原数组求交算术；实际优化查询的交点比例及boxId逐值相等，包括源顶点、随机斜线、出生附近水平／垂直射线和128单位边界。已纳入test:battlefield。
- `tests/network-integration.cts`验证独立连接、身份、房间隔离、原坐标范围的出生点、沿当前朝向的移动、开火、旧输入拒绝和退出清理。
- `tests/browser-battle.mjs`以两个独立Chromium窗口验证原地图、91个田野路实例、两个原模型、实际显示坐标与服务器坐标的X反射，以及移动、开火、16秒心跳保持和退出。

## 已知限制

出生记录由构造器0x45e3a9创建两个12项向量，0x45de7b以16字节步长计算项数；旧版本加载时仅填每项前12字节。这确认了记录步长，但出生数组的用途、队伍分组及第4个f32的单位仍待还原。部分文件槽位包含异常高度/朝向数据；运行时选择能与NAV有效单元高度对齐的非零位置，优先第一个数组，第一个不足两点时使用第二个。朝向暂按度数换算，是重建规则。所有原数据保持在导出文件中，尚不能认为600个槽位均已恢复正确业务语义。

身体半径20、TankMove乘6、360单位/秒弹速、30单位炮口偏移、20单位射击高度、球体命中、800ms装填、3秒重生及攻防公式均为临时规则。移动目前在障碍前停止，原版滑动、挤压、车体多点NAV采样及路径规则仍待还原。静态盒体不会随物件破坏更新，模型级可破坏物/城堡碰撞和伤害状态仍需接入。原地图材质/动画、炮塔原限制、动作及精确相机手感继续校准。全部21种源战车组合和独立炮塔瞄准已接入，验证与边界见 `tank-runtime.md`。五种模式目标与结算规则、原版UI、成长/社交及持久化仍未完成。
