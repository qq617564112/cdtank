# 登录与频道选择

正式入口由 React 管理 Login → Channel → Lobby。登录前不挂载大厅、聊天和社交消费者，账户和房间共用 GameConnection 的一条认证连接。验证入口保持独立。

原 login.xml 与 lobby_select.xml 提供 800×600 布局、背景、按钮图态、账号及密码输入、保存账号选择、频道名单和返回控件。输入限制20字符，密码遮蔽；动态文字使用项目指定字体。系统设置和游戏介绍从正式 Login 入口打开并返回。

账号认证为 Web 重建规则。注册将当前保存 token 对应的未绑定持久账户绑定账号；没有保存身份或保存身份已绑定账号时，创建独立账户。重复账号拒绝注册。账号密码登录返回相同 accountId/token，保存身份可用 token 恢复。账号区分大小写、去除首尾空白，密码不去除空白；均为1至20字符。SQLite 独立保存账号、随机盐及 scrypt 密码密钥。浏览器只保存持久 token 和用户选择记住的账号，密码不写入 localStorage。

注册同时分配原表初始猫“公主”（pet101）、初始狗“阿呆”（pet1）和初级坦克“小勇士”（tank1）。角色保存为真实拥有实例，宠物生命、凶猛、好运与技能定义，以及坦克基础攻防、默认贴图和部件容量读取原表；宠物技能等级采用现有新生宠物初值0。新账户建立0x170字节角色资料，默认选择公主与小勇士，未装备部件与资金初值为0。绑定已有身份时复用已拥有的初始角色，保留其他库存、余额、资料字符串与有效角色选择；未选择或失效的角色引用才补上默认选择。凭据、初始拥有记录和资料在同一注册事务内保存，失败整体回滚；登录和token恢复不再次分配。

频道目录由当前部署服务提供唯一 main 条目，名称“当前服务器”、等级“不限等级”。ENTER 验证稳定频道标识；未知频道拒绝。单部署频道确认不改变已有房间状态，保留 token 断线恢复的身份和房间语义。频道 Back 关闭连接并返回 Login，Close 关闭连接并进入退出页；可返回 Login 再登录。请求失败保留当前页面并显示错误。
