# 玩家信息页面呈现

大厅玩家信息入口使用 `myhome.xml` 根布局，内容区域为 625×404。关于我、猫狗、坦克和装备页沿原页签导航，页面内保留原图框、原按钮和原文字矩形。

- 关于我：武器、道具、贵重品及战绩、称号、奖章页签在原位置切换。快捷槽编号和数量使用 `myhome_playerpage.xml` 的 `txtLabel0..3`、`txtQuantity0..3`；拖放、点击配置、右键和 Delete 取消仍由同一快捷槽事务处理。
- 称号：原 `lstTitles` 名单显示已确认的拥有称号。点击佩戴，再次点击已佩戴行、右键或 Delete 取消佩戴，服务端确认后更新高亮和当前称号。
- 物品与装备说明：悬停或聚焦名单行时显示 `shop_itemdesc.xml` 原说明图框，坐标限制在当前玩家信息页面内；离开、滚动、切页和开始拖放时关闭说明。
- 查询、配置、选用和改装的通知使用原 `notify_dialog.xml`。贵重品未完成出售通过 `confirm_dialog.xml` 确认，同一请求重试保留原 requestId。
- 对局记录从大厅入口进入，键位和系统设置从设置入口进入，迷彩从商城原迷彩页签进入。

页面不附加常用操作栏、刷新统计、清空称号、迷彩跳转、装备详情段落或底部状态条。确认弹窗挂载在页面缩放容器外，沿 800×600 基准统一缩放。

## 验证范围

本范围完成静态源码和原 XML 矩形核对，未运行测试、构建、类型检查或浏览器验收。悬停／焦点触发、称号取消手势和未完成出售确认属于现网页交互映射；完整原客户端触发链及像素等价仍需原始来源和实际页面证据。
