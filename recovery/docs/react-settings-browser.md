# E-R04-S React设置真实浏览器验收

`tests/browser-react-settings.mjs`串行执行键位、备用键、快捷聊天和音量四个独立Chromium fixture，支持`--only=keys|secondary|quick|volume`。每次输出使用独立时间前缀，综合交付索引引用实际通过的各片证据。对应旧DOM设置已由单应用根下JSX接管，Babylon和Battle网络、输入、聊天、音频消费者继续由原模块持有。

## 已通过流程

- 键位：原生鼠标捕获与改键、重复/组合键拒绝、Tab取消捕获、冲突/默认/取消/保存；关闭及重开使capture keydown listener数回到基线。主键I/K/J/L/U/O/F贯通普通CPU房间的移动、转向、炮塔和开火snapshot；旧键失效，H快捷槽只请求一次，输入框、设置与Autopilot隔离。刷新、新页面、1080p/4K和同浏览器profile恢复通过。
- 备用键：普通W和I均真实移动；双持后释放主键仍移动，全部释放恢复中性；备用F真实开火，主Digit5与备用H保持快捷槽语义。主/备用冲突、清除、取消、默认、持久和高清通过。
- 快捷聊天：真实`Input.imeSetComposition`与`Input.insertText`验证中文组合和提交。八个F5–F12均由真实RoomChat确认并同步两网页；重复按键只发送一次，空条、组合键、编辑框和设置不发送，未发送普通聊天草稿保留。72字符、控制字符拒绝、默认/取消/保存、刷新、高清、断线恢复与浏览器profile重开通过。损坏存储回到空默认，拒读显示提示，拒写不更新正式消费者，关闭重开丢弃未确认草稿。
- 音量：普通range键盘从0到非零，真实music、EffectSound与EffectSkillSound消费者实时变化；独立声道、正常离房和静音重进验证。GA15原文件由正式音频后端实际播放，analyser实际峰值0.067477→0→0.269908。刷新、新页面、同Chromeprofile正常退出重开及存储诊断按独立证据记录。
