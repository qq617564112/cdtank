# 全图Breach原资源绑定

对应M3-02、M3-05、M3-07、M3-08。`export_scenes.py`在读取全部25图原放置后调用`export_scene_breach_catalog.export`，按`SYcScnObjBreach`实际型号查找该型号目录的`c9.CVD`或原始归档大写`C9.CVD`，复用现`export_models`保留原节点槽、父索引、轨道、材质和纹理引用。

有自身c9的记录写入`destruction.library=scene-breach-catalog.json`及精确`destruction.reference=Data/scnobj/<model>/c9.CVD`或`C9.CVD`。共享库每型号只导出一次；当前生产入口只导出05438、05440、05441、05446和05463五种fallback，库的`missingResources`保留真实缺项，本次为空。25个已发布型号优先选既有地图库或型号库，其catalog字段只保留元数据来源关系。`export_asset_usage.py`从当前selector读取已发布型号范围，仅将fallback型号的放置绑定关联到`SceneBreachVisual.load → fetch(this.libraryAsset)`；索引不声称实际加载通过。

现有25个原场景共有1144个Breach、30个型号。25个型号共1046个放置继续优先复用已发布的地图/型号库；05438、05440、05441、05446和05463共98个放置由本共享库发布，其中17个使用小写`c9.CVD`，81个使用原始`C9.CVD`。已接受地图及既有精确地图库仍优先使用当前消费者。

## 未完成范围

05440、05441和05438的原`C9.CVD`及同目录POL/DDS均已从原CPK和verified来源确认；共享catalog保留原始reference大小写、13/5/6个节点槽、169/65/78个顶点帧和节点动画轨道。05446和05463的完好POL共用原`line02/0`、`object01/0`、打包顶点RGBA及同目录A/TGA纹理。五种fallback的完好材质正式消费者按原型号分别注册，并继续沿revision/clear先恢复材质再释放资产。

共享库和98个placement绑定已写入本地runtime资源目录`recovery/output/web-assets`，并由任务结果目录的`breach-assets.json`列出供发布。已有静态`C9.glb`不作为frame驱动破损消费者替代；浏览器加载、实际破损动画、声音、双端像素、原GPU及整图仍是本父项之外的未验范围。

原m001–m005提供13图26组合的直接参数来源；当前房间目录已经开放0001–0025，新增模式组合采用同模式首条原记录参数，占领仅开放具有真实Castle的11图。地图资格与资源发布分别由房间目录和资源消费者负责，详[可玩地图](../../docs/playable-maps.md)。原HP、命中权限、动态NAV、刷新、掉落、其它场景类语义及完整地图实际表现仍按各父项开放，代码走查不替代运行或原来源证据。
