# 战斗视觉车体 NAV 坡面

## 高度直接来源

`NavigationGrid` 直接保留原 NAV v2 每格 f32 高度与四个附加字节；`sample` 使用原 `0x433f92` 的 f32 `1/12`、向零取整和 `width * z + x` 下标，`valid` 使用附加字段低字节大于 1。查询证据见 `navigation-format.md` 与 `role-movement-real-nav.md`。本轮没有另建地形高度、重力或垂直碰撞数据。

## 视觉采用规则

`BattlePlayers.render` 在权威 `bodyYaw` 与物理 Y 更新后，按当前插值显示的根节点水平朝向仅设置视觉根节点 pitch/roll。当前运动构造尺寸为 49×52：前方/后方沿源车体前向各采样 `52 / 2`，Babylon 根局部 +X 对应源 `(-cos(yaw), sin(yaw))`，两侧各采样 `49 / 2`。中心或任一侧无有效 NAV 时回到平面。车体实际显示 Y（本机为 local pose 物理/插值 Y，其余为快照插值 Y）高于采样面超过贴地容差 `0.5` 时直接回到平面，使下落、腾空或跨落差经过坡面时不会仍按地面坡面倾斜；离地归平只用本人显示 Y，不借用对方权威 Y 顶替。角度按两端高度差与完整尺寸计算，不设未知最大坡度。

根节点继续使用 `rotation.y = -bodyYaw` 保存原 X 反射后的车体水平朝向；pitch/roll 只影响渲染车体，不改炮塔 yaw、相机、挂点矩阵归属、移动或命中 authority。物理 Y、重力与地面接触由共享 `tank-vertical.ts` 单独处理（见 `battle-vertical-physics.md`），本坡面角不回灌水平核或物理。死亡、换车和再战走平面或新根节点，不保留旧坡面角。

## 原物理缺口

原 `0x433190`、`0x433073` 之后的完整垂直后处理、gravity、各车最终 OBB 尺寸或原始斜坡物理仍未取得。垂直运动已按明确项目采用规则接入（`tank-vertical.ts`），不是原垂直 physics 等价实现；坡面姿态是视觉采用规则，物理 Y 由独立垂直步负责。
