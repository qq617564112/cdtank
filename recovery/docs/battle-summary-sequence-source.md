# 战斗结算时序与成长回执

正式结算依次播放面板入场、玩家行入场、胜负图、滚分、实际奖项、等级与经验变化、四值奖励、新称号、已确认装备提示和奖励层渐隐。账户结算回执附带事务内读取的结算前累计积分；服务端与网页共用原等级门槛。收到重复快照不重新演出；结算回执迟到时从成长段继续。再战、换局与离房清理动画时钟和提示定时器。

## 原客户端依据

读取`current-exe.asm`和`CDTank.exe`中的分派表、函数与浮点常量，未执行原生取证脚本。

## 服务端和网页接线

`computeResultAward`在账户结算事务中将`previous.rankPoints`写入`ResultAward.rankPointsBefore`，与最终`rankPoints/levelBefore/levelAfter/expPercent`一起写入奖励流水。协议版本105新增ResultAward字段9，原字段编号保持。旧持久回执没有该字段，直接显示最终成长状态；不从最终百分比猜旧积分。

原`level.dat`的1–20级门槛由`apps/shared/settlement/account-growth.ts`统一保存，奖励算法与逐级经验显示共用。上升时每段填至下一门槛并切级，下降时每段降至当前门槛再切到下一级，最后一段到真实最终积分。同级变化为1秒。20级仍采用账户既有100%显示规则。

`battle-summary-sequence.ts`持有本局时钟，快照刷新、再战投票及翻页不重播。late receipt只续播成长和后续提示。面板和行入场由CSS动画完成；滚分和经验按时钟投影，奖项仍使用实际RoundAward。四值页不再阻塞等待人工关闭，3.2秒后自动显示新增称号，结束后奖励层1秒渐隐。原mode5右侧`picDogDestroyItem`没有Image属性，网页复用左侧原`diwushu.tga`列头。

结算阶段、实际奖项、等级变化、四值奖励和新称号现已接原音效；颁奖循环UI38在成长前停止，滚分及经验阶段逐帧请求UI29。音量使用Battle当前运行设置，重复快照不重播，离房和换局清理声部。原调用点及网页调度差异见`battle-summary-audio-source.md`。

## 限制

当前Web结算仍等待真实再战投票或退出，因此末段只渐隐奖励层，保留结果名单、分页及再战/退出入口；没有按原客户端自动返回外层页面。道具/坦克结果记录的接收链未包含发放条件或概率，当前事务没有该类奖励producer。原完整FontScoreHT、所有控件、原GPU与高清视觉一致性仍待验收。只完成一次集中静态走查，未运行测试、浏览器、构建、类型检查或lint；M5-04/M5-05/M5-06父项保持未完成。
