# M7-03 源最大人数模式/地图实时矩阵

剩余25个合法模式/地图组合使用同一编译服务顺序运行。mode5/map20复用 `complex-map-max-players-accepted.json` 的原最大12人60秒证据。

入口为 `npm run test:server:source-max-maps`，编译服务必须先由必要的 `npm run build:server` 生成。每房使用两普通空账户、默认战车1、源 `ListMaps.maxPlayers - 2` 个普通 CPU。通过正式 ADD/CONFIGURE/Ready/Autopilot 建立寻路、碰撞、攻击和道具负载，不导入账户资金、拥有物或活跃状态。CPU临时库存沿现有明确重建配置政策。

每房观察60秒或原玩法自然终局。逐房保存源配置、真实时长、完整双端快照与事件、服务端及墙钟间隔、普通Leave和房间清除。只读计时器包装编译World.step，不改变调用结果，以wallAt归属各房实际观察窗口。World单步50ms、快照serverTime间隔150ms为既有门槛，失败不降低门槛。

## 限定范围

两网络客户端和CPU演员不代表最大真人网络扇出。自然终局仅证明实际战斗持续时长；配置弹药/道具负载不覆盖每项技能。四角色加速时钟的既有全26图双自然回合证据继续独立有效，不代替实时最大人数结果。M7-03完整性能与HD父项保持开放。
