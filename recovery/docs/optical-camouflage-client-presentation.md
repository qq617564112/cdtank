# M4-10-I09 光学迷彩客户端显示

服务端按已确认的普通自用施放投影 `PlayerSnapshot.opticalCamouflage = {skillId: 9, expiresAt}`。BattlePlayers 只读取该权威字段与 `isHiddenByOpticalCamouflage(target, observer, mode)` 判定，不自行计时，也不在本地推定施放成功。

## 观察规则

`isHiddenByOpticalCamouflage` 对存活、skill9 生效、且非观察者自身的角色，在观察者为敌对时返回真。本机始终可见；团队模式1–3中同队可见，仅敌对队伍隐藏；混战/破坏模式4–5中其他所有参与者均视为敌对。网页据此对敌对角色的战车 root 调用 `setEnabled(false)`，其他情形保持 root 启用。

隐藏只作用于该角色的模型 root。相机、选择、位置、插值、动作状态、模型生命周期、现有特效归属及原伤害/收益/暴击图片均不改变：临时隐身不释放或重载战车，也不改变 root 的动作启用状态本身。弹丸、全局 HUD 名册和伤害数字不在此隐藏范围。

## 生命周期与载入

可见性由服务端快照驱动。快照中该项移除、到期、角色死亡、结算或换局时恢复显示；`playing=false` 时一律显示角色。继续渲染/对账会按最新快照、观察者与模式重算可见性，切换观察者、队伍或模式同样重算。`clear()` 归还全部普通状态与观察者/模式默认值。

迟到的战车载入在插入场景并将资源挂到特效系统之前，使用当时的快照、观察者与模式设置可见性，避免隐藏敌人短暂出现。

## 范围

不新增 Effect、Sound、透明度、标记索引或额外绘制来源，不把隐身当作碰撞免疫或无敌，也不因普通开火取消。CPU 配置界面槽5–8按已确认目录开放物件9（上限仍取该物件 BattleUseMax）；购买、键盘焦点、保存与生成沿既有流程。
