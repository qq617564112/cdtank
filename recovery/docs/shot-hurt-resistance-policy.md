# 不怕痛与受击动作

本片 Web 规则将当前合格目标的完整抗硬直比例用于普通炮击的受击动作资格：`attributesReady` 且 `combat.roleFloatFields[0x90] >= 1` 时，该次 hit 不携带 hurtSelector。现有客户端仍显示伤害文字并执行弹药 Trigger8，实际 HP、得分、暴击和生命吸收均按正常规则计算。角色不会派发受击动作05..08；现有本机三部件受击相机同样不会激活。无资格或比例零保留现有 selector。医疗弹先由现有医疗入口处理，周期伤害保持原路径。
