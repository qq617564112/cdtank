# 宠物技能战斗生命周期

`PlayerState.petBattle` 持有当前玩家的宠物处理器。`apps/shared/content/definitions/pets/{petId}.json` 为十只宠物分别配置技能基础 ID、已学初值、等级上限、各级技能引用、事件、处理器、目标与条件；启动时读取配置，战斗事件动态查表分发。各等级按 `levels[rank - 1]` 引用 `skills/{skillId}.json`，不生效的零级与未开放第六槽不派发。名称、说明、价格、模型与贴图同样读取该宠物定义，目录结构与维护方式见 [game-content-definitions.md](game-content-definitions.md)。

事件使用实际战斗结果：受击须有敌对生命损失且存活；击毁在最终死亡确认后派发；死亡授予队友效果后统一清理；真实复活派发重生技能，首局出生只初始化常驻效果；移动与静止按每次 actor 推进后的已接受 XYZ 位移判定，涵盖人工、CPU 与托管路径。`setBattleHealth` 通知生命变化，低血量效果在损伤、治疗时同步加入或撤回。

## 路由与数值

配置示例，大麦得意：

```json
{"baseId": 10211, "initialRank": 0, "rankCap": 5, "levels": [10211, 10212, 10213, 10214, 10215], "event": "kill", "handler": "heal", "target": "self"}
```

`attributes` 复用生命、弹药、移动、攻防与概率的原属性重算；`heal` 复用生命夹取和治疗事件；`copy` 写入每生命唯一额外技能。`backCritical` 与 `lastStand` 由原弹药与致死入口读取 JSON 中的处理器路由，保留现背面暴击追加伤害和延迟死亡规则。

大麦得意 1–5 级分别恢复 40／80／120／160／200 生命；大麦耍赖 1–5 级均持续原 Func1.T 的 5 秒，移动增量使用各级 ItemMove。静止治疗周期取 Func2.X：黄金母舰 1–5 级为 5 秒，6 级为 4 秒；移动打断周期，重新静止后重新计时。

属性效果独立于原十六个道具／动作槽，经 `runtimeSkillIds` 输入统一重算，快照的 `selectedSkillIds` 公布实际生效技能。相同技能家族不重复叠加；同级限时效果刷新期限，较高级覆盖较低级。不同家族沿原属性累加规则组合。死亡、离房、结束、再战撤回临时来源，复活建立新生命状态。

队友效果只用于模式 1–3 的同队存活角色；`teammates` 排除本人，指挥使用 `team`，包含本人。多人指挥按技能 ID 去重。指挥来源死亡或离房撤回，复活时重新传播；已发出的限时队友效果持续到各自期限，受益者死亡时撤回。

## 模仿

候选为受害者冻结选用宠物的已学技能，包含被动、移动、静止、低血量、受击、击毁、死亡、复活、背面暴击与最后一搏；不包含模仿本身、装备物品、未学技能或受害者的复制来源。一次随机均匀选择，覆盖唯一额外技能，当前生命内有效。被复制技能使用相同 JSON 路由和等级参数；同家族已有技能采用较高级，不重复累计。

一次击毁先执行事件开始时已有技能，再执行模仿；新复制的击毁技能从下次击毁生效。替换时撤回旧复制来源的本人限时效果并重置复制的周期治疗；常驻队友效果重新计算。无需改写账户技能、学习记录或库存。

## 采用的项目规则

好运作为一次敌对弹药攻击的闪避概率，消费属性重算后的 `roleFloatFields[0x6c]`。无敌与每生命抵消优先；闪避不扣生命、不触发受击技能、吸血或命中奖励。医疗与队友攻击不走好运；直接技能伤害与持续伤害不走弹药闪避。原好运服务端执行器未恢复。

VIP 使用地图固定生命上限，完整拥有来源仍执行普通宠物与战车属性重算；不再因未知原 VIP 生命倍率让所有宠物消费者停在未就绪状态。

字段与文字冲突时采用字段：毛姐复活最高级 Func1.T=15 秒，文字写 20 秒；刽子猫受击射速 Func1.T=5 秒，文字写 3 秒；指挥实际 Critical=4、Lucky=8，文字写 6／10。
