# 原运动包装与碰撞失败合同

255组完整`0x435088`执行和断言通过：command0–8，delta−0.05/0/0.05/0.2/0.4，null地图、全通行、全阻挡、首侧/末侧阻挡及存在不同内部采样点时的内部阻挡。150组返回true，80组组合命令重试，其中60组重试成功；24组返回false但方向改变。每组验证返回值、栈、位置/look/forward公式、碰撞检查结果、尝试命令及delta、matrix和center保持。

## 原执行范围

`0x435088`完整执行，包括`0x434cee`以复制的姿态试算、原采样点生成、归一化/轴旋转、格子检查和失败分支。地图访问链`0x4340c5 → 0x434008/0x433f92 → 0x433fdd/0x45758f`，边界检查`0x44ef9e`全部执行原指令。hook只读观察入口和返回，不供给服务或改寄存器。原数学函数不替代。

夹具供给100×100合成原结构格子，origin=[0,0,0]，每格8字节，字节+4为2表示可通行、0表示阻挡。`0x45758f`实际判定为字节+4>1；越界返回false。`0x433f92`把世界X/Z减地图origin，乘原float32(1/12)，按原`0x57bb64`转换为格子索引。本组footprint由19 DWORD矩阵块后部+0x40/+0x48分别供给48；记录中保留全部格子查询。静态单侧/内部障碍设置后不随尝试修改。

## 时间与提交

`0x435094–0x4350a4`把delta上限截为float32(0.2)，直接传给每次碰撞试算和最终运动提交。delta0.4各姿态结果等于delta0.2；负delta与零delta也传入，没有下限或提前返回。上游`0x433190`的delta≤0拒绝属于不同入口，未在本组执行。

`0x434cee`只修改姿态的栈复制值，不提交试算。null地图立即允许，随后仍由wrapper完整执行`0x4344e7`。有地图时检测通过后再次调用`0x4344e7`提交选定命令。初始X/Z=[200,200]、look=forward=[1,0,0]，速度30、转向率0.5、TankType1；公式见role-movement-commands.md，按受限delta断言。

## 失败与返回

| 原命令 | 首次失败之后 |
| --- | --- |
| 5、8 | 改command4原地转向，再执行完整碰撞检测 |
| 6、7 | 改command3原地转向，再执行完整碰撞检测 |
| 0、3、4 | 返回false，位置与两个方向保持 |
| 1、2 | 返回false，位置保持；失败code0/1分别让look和forward旋转−/+float32(turnVelocity×delta)，code2保持方向 |

原退化发生于`0x435110–0x43512b`，重试回到时间限幅与完整试算。命令3/4重试通过，wrapper返回true并提交原地转向；再次失败则返回false且不提交。首侧与末侧通行位的映射随前进/倒退检查顺序不同，原失败code0/1断言由实际两端格子通行值独立计算；内部采样失败还可产生code0/1。成功路径的code槽没有统一初始化合同，本产物只把失败code作为有意义值。

位置失败保持不等于全部状态回滚。例如command1、delta0.05、首侧阻挡：位置仍[200,0,200]，返回false，两个方向约[0.9996875,0,−0.0249974]。command5同障碍会退command4，保持位置但look约[0.9996875,0,+0.0249974]并返回true。

每组matrix的76字节及center哨兵[987,654,321]保持，包括成功、拒绝和重试。wrapper消费matrix副本作为采样形状，不在此更新世界姿态矩阵；caller `0x433190`随后调用`0x433073`更新矩阵。wrapper中的center指针参数未参与本入口的运动提交。

## 接线范围与缺口

本证据支持实现已验证的delta上限、试算后提交、组合命令退化、失败部分方向转动与返回合同。不能把false统一处理成完全回滚，也不能把组合运动碰撞失败统一停止全部转向。

合成格子不是原地图loader、原真实地图障碍或World当前碰撞实现的等价证明。只执行TankType1、同向初始look/forward和48×48footprint；其他类型、异向碰撞与更多形状仍待取证。controller命令门禁、上游时钟单位与`0x433190/0x433073`完整调用未执行。生产还需明确当前地图如何对应原格子/footprint、输入如何对应原command，不能据此宣称原碰撞全部恢复。

复现：`recovery/.venv/bin/python recovery/evidence/movement/role-movement-wrapper-native.py`。同名JSON含每次原尝试/采样/姿态，log保存通过结果，disasm保留原调用与常数。
