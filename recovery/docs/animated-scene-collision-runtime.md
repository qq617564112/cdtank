# 动画场景碰撞与共同局时钟

场景 CVD 的节点变换、逐顶点帧与 GLB 的节点／morph 帧在服务端按局时钟采样，只替换动画实例的射击网格和 NAV 占用。静态网格仍缓存；每帧网格不进入静态占用缓存。客户端通过快照 animatedBlockers 替换同放置 ID 的预导出占用，避免叠加旧碰撞。

CVD 渲染与碰撞共用轨道、四元数、缩放和顶点插值。每个节点独立循环自己的 duration，严格超过末帧才循环。Castle 的动作读取接受的扣血／修复事务，动作起点随场景实体投影；原 MV3 4800 单位／秒与发布 GLB 的单位／1000 时间共同换算。死亡沿用两秒碰撞退出，普通 Breach 同实例重生恢复资格。

植物保持可穿行。植物摆动的局时钟与放置初相同时用于顶点绘制和接触包围盒，接触隐藏继续走原 type100 通知。原 rand15 在本项目采用放置 ID 对应的确定初相；变形后包围盒是接触几何的项目采用。

本轮仅静态走查，没有新增或运行测试、浏览器验收、构建、类型检查或原客户端实测。原来源和实测父任务保持开放。
