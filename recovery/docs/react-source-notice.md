# React 服务器拒绝提示

E-R05-N 将等待房间的真实服务器拒绝提示迁到 React。`SourceNotice` 只保存当前会话、源资源和关闭完成 promise；`SourceNoticeView` 拥有原 notify_dialog 的页面、图像、文字、控件状态、焦点与缩放。等待房间每个 room/round/phase 会话创建独立控制器，清理使迟到载入失效并解除等待，不复用全局旧 DOM 对话框。

正式入口保持普通邀请→服务器 INVITE_EMPTY→源提示→玩家关闭→等待房间恢复请求的行为。提示出现前的等待控件仍 busy，关闭后由请求 finally 恢复控件与焦点。React 使用原资源、原坐标和原有边框投影；本次迁移不把通知边框固定20px、浏览器 backdrop 或默认字体映射宣称为原 CEGUI 完整1:1。

组件捕获组合输入与键盘事件，保留原生 dialog 的鼠键命中、Tab 焦点约束、Enter 确认和 Esc 关闭；resize 监听随组件清理，离房或阶段变化卸载整个会话与页面。原通知资源载入失败保持现有等待房间错误文字。

验收以真实邀请拒绝专项提供；组件或状态供给不能代替服务器请求。
