# 战斗快捷栏、弹匣及本地生命条原图绘制

`BattleHudVectorRenderer` 使用原客户端发布 PNG 绘制快捷栏、道具图标、无限符号、
冷却遮罩、弹匣与本地生命条。`battle-hud-vector-geometry.ts` 保存151项原图路径及
源尺寸，其中144项为战斗目录引用的道具图标。

原区域77/7、77/17、77/18、77/20、77/21、77/70和2/0直接用于绘制。
载入阶段复用图片解码缓存；屏幕覆盖层提供位置、透明度、裁剪及 RGB 颜色相乘。
生命条原白色填充随0.34/0.67阈值调色；数字及快捷按钮图形交给统一 WebGL 绘制层，
DOM 保留布局、快捷按钮交互与可访问属性。完整范围见 `battle-ui-drawing-layer.md`。

```sh
python3 recovery/export_battle_hud_vectors.py
```

弹匣宽度保持 `capacity × 15`，余弹取服务端数据；背景和填充按原 AutoScaled
取整尺寸平铺与裁剪。原800×600坐标、快捷栏左侧锚定、生命条居中位置和观战隐藏
保持。离场清理图形，场景销毁移除覆盖层。
