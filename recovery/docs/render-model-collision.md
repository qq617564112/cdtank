# 地图渲染模型碰撞

服务端地图碰撞从网页载入的渲染几何生成。`scene-placements.json` 指定地形 GLB、物件 GLB/CVD 和实例变换；`battlefields.json` 提供出生点和原始 NAV 通行区域。静态地图射击碰撞不再读取 `.box` 导出的虚拟包围盒。

| 对象 | 几何来源 | 参与规则 |
| --- | --- | --- |
| 地形 | 场景条目的 `terrain` GLB | 三角面射击碰撞、地面高度查询；垂直面生成导航占用 |
| Breach | 放置记录的 `asset` GLB | 完整模型三角面；销毁后严格超过 2000ms 移除 |
| General | 放置记录的 GLB 或 `animation.library/reference` CVD | 三角面；CVD 使用时间零的节点变换与顶点帧 |
| Castle | 地图 2/5/6/10/11 的 `scene-castle-*.json` 中 `n1` GLB；其余场景使用放置资源 | 初始模型三角面；沿用房间城堡生命周期 |
| Crush | 放置记录的 GLB | 启用且可见时参与；隐藏后立即释放；普通射击的高度无关查询使用三角面的 XZ 投影 |
| Plant | 原有接触记录 | 沿用植被接触隐藏和可穿行规则 |

## 放置与判定

GLB 加载器读取节点层级、矩阵/TRS、POSITION、索引、bufferView/accessor 偏移及步长和初始 morph 权重。CVD 加载器读取时间零的变换轨道、父节点、顶点帧和分部索引。

物件放置采用记录矩阵的线性部分，平移替换为 `position`。记录矩阵原有的平移是包围盒中心，不能作为渲染几何原点。服务端保留原始坐标，网页显示时反射 X。

弹丸半径通过球体扫掠与三角面的两侧、边及顶点求交。128 单位空间格和模型 AABB 仅筛选候选，最终碰撞由三角面确定。零厚度薄墙正常参与，无额外厚度。地图 20 的所有 Breach 目标，包括 obj05434/05435/05436，采用同一规则。

导航占用由模型三角面与 12 单位网格的站立棱柱相交生成，棱柱高度为 NAV 地面上方 0.5 至 24 单位。地形只将垂直面计入额外占用，坡面继续沿用原 NAV 地面高度与通行标记。角色保留原来的 49×52 足迹采样；移动路径补充不超过 6 单位的中间采样，CPU 路线使用相同导航占用。

动态目标接管对应 `SCN:<placement>` 静态实例，使用目标业务 ID 返回命中。销毁释放动态碰撞及网格占用后，静态副本仍保持停用；下一轮目标恢复时重新登记。重叠占用通过现有网格引用计数分别释放。不可破坏的静态实例保持常驻。

## 限制与验收

- 动画几何采用初始姿态；城堡动作、CVD 后续帧、破坏动画和植被摆动不逐帧改变碰撞。破坏淡出期间保留完整模型碰撞。
- 导航保留原始 NAV 通行边界和高度，新增模型占用按 12 单位格离散；解除模型占用不会把原 NAV 禁行区域改成可通行区域。
- 三角面碰撞不按材质透明度裁剪。没有发布渲染模型的物件不生成模型碰撞。
- 本次只进行集中源码走查，未运行测试、构建、类型检查或浏览器验收；地图实测和运行时开销仍待验收。
