# 页面静态资源加载

设置、我的家、商城、交易、等待房间、战斗HUD、聊天、结算及使用 `useSourceUi` 的页面共用静态目录缓存。`assets/static-resources.ts` 按URL共享请求Promise和解析结果；相同目录在一次应用运行期间只请求和解析一次，失败后删除该项，下次载入重新请求。页面卸载只停止更新自身状态，共享请求由加载器管理。

纳入缓存的目录包括 `ui.json`、`ui-fonts.json`、`combat-catalog.json`、`tanks.json`、`tank-textures.json` 和 `chat-emote-sequences.json`。战斗角色和场景文字也复用UI及字体目录。账户、库存、商城等业务查询继续读取服务端当前状态。

JSON请求及响应体读取使用30秒超时，超时中止请求。原界面图片解码和动态字体加载也设置30秒超时；失败清除对应Promise缓存。设置页和大厅提供原地重试，其余页面通过重新打开或既有资源重试入口再次载入。

页面复用 `loadUiFont` 加载当前选用的香蕉字体，启动图片加载页也复用同一Promise。字体采用 `font-display: swap` 和30秒超时；页面内容不再等待字体加载。原完整SIMSUN动态字体不参与当前页面加载，战斗伤害等静态字形仍读取 `ui-fonts.json` 并等待其必要图像资源。字体加载完成后重新计算聊天换行和输入光标位置。

JSON、图片和字体已经作为Vite的public静态资源随前端发布，运行时按需读取。大型目录保留独立文件，避免扩大入口JavaScript；页面切换复用内存中的解析结果。浏览器刷新后仍读取静态资源，HTTP缓存沿用发布服务规则。

首次Loading在下载完成后解码全部发布图片及源码打包图片，再进入游戏。页面图片准备与Loading共用 `assets/image-resources.ts` 的解码缓存，后续页面直接复用；失败重试保留成功图片。图片缓存命中只代表下载已完成，本次应用启动仍等待全量解码。详见 `image-loading-runtime.md`。
