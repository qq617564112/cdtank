## 玩家入口与状态

临时SQLite通过原生backup复制已有合法购入战车检查点，账户身份严格保持。每局通过正式Shop购买道具4六份，并在Home配置槽4（Digit5）。一次正式BUY17031及EQUIP槽0贯穿六局。没有新资金、角色或库存记录导入，没有活跃位置、生命、伤害、事件或结果注入。

正式命令为 `npm run test:server:continuous-sessions`。只读观察调用原有方法，不改返回值或对局状态。完整原始输出与失败记录保存在 `recovery/output/browser-continuous-sessions-*.json`。
