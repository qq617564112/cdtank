# 战斗 UI 统一绘制层

`BattleUiLayer` 在世界、雷达和战车头顶标签完成后，通过一张动态纹理与屏幕四边形
绘制战斗界面。`BattleScreenVector` 的原图、裁剪、颜色及透明度进入同一 WebGL 层。

| 界面 | 绘制内容 |
| --- | --- |
| 主 HUD | 玩家头像、昵称、称号、VIP 标记、模式信息、计时、复活提示、战斗消息 |
| 快捷栏 | 原图、数量、快捷键、冷却数字、选中边框、鼠标与键盘焦点反馈 |
| 观战 | 背景、当前友军名称、前后切换按钮 |
| 聊天 | 面板、富文本、表情动画、频道及密语菜单、滚动条、输入文字、选区和光标 |
| 战斗操作 | 离房按钮、反馈及退出确认内容和遮罩 |
| Tab 计分板 | 背景、头像、名单、统计、分页与提示 |
| 结束与结算 | 结束提示、胜负、队伍名单、奖励、成长进度、装备与称号通知、继续按钮 |
| 原屏幕图形 | 血条、弹匣、准星、模式说明及伤害、回血、暴击、Combo 飘字 |

DOM 保留控件布局、焦点、点击、滚动、输入法和可访问性绑定。控件的可见内容由
`BattleUiRaster` 消费实际字体、文字位置、图片、边框、裁剪及动画状态后交给绘制层。
原图与染色图片复用解码缓存；没有内容变化时复用纹理，动画期间逐帧更新。

模式爆花、说明与标题位于 HUD 之上；计分板、结算及模态内容保持各自绘制顺序。
模态遮罩随模态内容绘制，原生模态继续承担输入门禁。场景隐藏或销毁时释放绘制
绑定、观察者、事件订阅和 GPU 资源。

## 验证范围

完成源码入口、原控件布局、图片引用、更新与释放路径的静态核对。未运行测试、
浏览器验收、构建或类型检查；动态效果及交互表现仍需实际页面验收。
